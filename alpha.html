The Alpha Release

A dual-interface architecture bridging a simulated physical world with a real-world decentralized mesh network.

Oasis Engine

Layer 1: The Physical Sandbox

Oasis is a WASM-compiled C++20 voxel simulation that runs directly in your desktop browser. It acts as the physical digital twin for the Sovereign Stack.

Mechanics: You are Founder 01. You must navigate brutal thermodynamic realities, construct physical infrastructure (solar panels, water catchments), and manage your caloric burn. It is entirely isolated from the outside world, acting purely as a mechanical testbed for infrastructure layouts.

Cadastral Slate

Layer 6: The Mobile Companion

The Companion App is the true "Trojan Horse". It is a mobile-responsive web dashboard that connects to native POSIX daemons running on your machine.

Mechanics: While your desktop runs the physical game, your phone runs the societal interface. You use the Companion App to sign mutual aid treaties, monitor Layer 4 execution telemetry, and trade Exergy Credits on the Agora. The app trains you to operate a real decentralized network.

Accessing the Software

The Alpha relies on two interconnected systems: the WASM WebGL frontend and the native C++ POSIX daemons (`col-gatewayd`, `col-meshd`, etc.) that handle networking and state.

To launch the development environment locally on a Mac or Linux machine, clone the repository and run the dev script. This will compile the engine and spin up local servers for both Oasis (Desktop) and the Companion App (Mobile).

$ git clone https://github.com/raffaine/collective.git
$ cd collective
$ ./scripts/start_dev.sh

> [3/4] Starting Sovereign Stack Daemons...
> -> col-gatewayd running on port 8443
> [4/4] Starting Local Web Servers...
> -> Oasis Engine (Layer 1) running at: http://localhost:8080
> -> Companion App (Layer 6) running at: http://localhost:8081

Packaged alpha release binaries are generated automatically via ./scripts/build_release.sh.
