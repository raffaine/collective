## 1. Problem Statement & Legacy Failure

In legacy late-stage capitalist infrastructure (Layer 7), short-term travel and hospitality have been aggressively captured by extractive surveillance platforms. These centralized intermediaries extract 1500 to 3000 basis points (15% to 30%) of gross transaction value from hosts and guests while offering zero genuine support when physical disputes arise.

When a traveler seeks temporary shelter or a community offers hospitality:
*   **Monopoly Rent Extraction & Platform Enclosure:** Commercial platforms extract massive transaction cuts, forcing hosts to inflate prices while subjecting users to centralized algorithms that can arbitrarily deplatform travelers without appeal, erasing accrued reputation.
*   **Housing Distortion & Community Displacement:** Speculative corporate investors purchase entire residential neighborhoods for full-time vacation rentals, destroying long-term housing stock and prompting municipal governments to impose blanket bans that penalize mutualist homestays.
*   **Unmetered Thermodynamic Externalities:** Legacy vacation rentals ignore energy efficiency. Guests routinely run air conditioning at low temperatures with windows open or take excessive hot showers, externalizing utility costs onto hosts and exacerbating regional grid stress.
*   **Precarious Gig-Economy Housekeeping:** Turnover cleaning is offloaded to precarious, underpaid gig-workers through on-demand cleaning apps, creating high stress, invisible exploitation, and low operational reliability.

4.  **Bulk Group Purchasing Organization (GPO):**
    Commercial-grade natural latex mattresses, certified organic linen sets, and ultra-low-flow plumbing fixtures are procured through the cooperative's non-profit GPO, securing wholesale pricing while eliminating packaging waste.

## 4. Oasis Engine Implementation Specification

### 4.1 Memory Allocation & Voxel State
The micro-lodging suite occupies dedicated coordinate space within the $32^3$ chunk grid:
*   The suite control terminal is initialized with `material_id = 70` (`LODGING_SUITE_TERMINAL`).
*   The entrance door voxel is initialized with `material_id = 71` (`SMART_LOCK_DOOR_VOXEL`), setting `metadata` bit 0 for locked state and bit 1 for actuator.
*   Active bookings lock the room volume (`temporal_voxel_lock`), preventing unauthorized player entities from editing interior voxels or taking stored provisions.

### 4.2 C++20 Test Harness Code

```cpp
// engine/tests/scenario_zeta_test.cpp
#include <cassert>
#include <cstdint>
#include <string>
#include "oasis/chunk_manager.hpp"
#include "oasis/orchestration/bpmn_engine.hpp"

namespace oasis {

struct LodgingUnitFixed {
    uint32_t room_id;
    std::string current_guest_handle;
    uint64_t checkout_tick;
    bool is_locked;
};

struct UtilityMeterAccumulatorFixed {
    uint64_t cumulative_energy_uj;
    uint32_t cumulative_water_ml;
    uint32_t current_noise_cb;
};

struct BccLodgingChannel {
    std::string peer_u;
    std::string peer_v;
    int64_t balance_u_to_v_uj{0}; // Conservation: B_{u->v} + B_{v->u} == 0
    int64_t credit_limit_uj{300000000000000ULL}; // 300 MJ
};

inline bool verify_lodging_bcc_conservation(const BccLodgingChannel& c1, const BccLodgingChannel& c2) {
    return (c1.balance_u_to_v_uj + c2.balance_u_to_v_uj) == 0;
}

struct LodgingJobContextFixed {
    std::string bounty_id;
    uint32_t nights_count;
    uint64_t base_rate_uj;
    uint64_t barter_offset_uj;
    uint64_t estimated_utility_uj;
    uint32_t target_suite_id;
};

} // namespace oasis

void test_scenario_zeta_lodging_normal_execution() {
    using namespace oasis;

    ChunkManager chunk_mgr;
    chunk_mgr.allocate_chunk(0, 0, 0);

    // Initialize Door Voxel (Locked by default)
    Voxel door_voxel{
        .material_id = 71, // SMART_LOCK_DOOR_VOXEL
        .moisture = 0,
        .temperature = 293150, // 293150 mK
        .metadata = 0b00000011 // Locked (bit 0) + Actuator (bit 1)
    };
    chunk_mgr.set_voxel(16, 8, 16, door_voxel);

    // Setup Pairwise Bilateral Clearing Channel between Node 04 (Host) and Node 09 (Traveler Kai)
    BccLodgingChannel ch_host_guest{"node04_host", "node09_guest", 0, 300000000000000ULL};
    BccLodgingChannel ch_guest_host{"node09_guest", "node04_host", 0, 300000000000000ULL};
    assert(verify_lodging_bcc_conservation(ch_host_guest, ch_guest_host));

    BPMNEngine orchestrator;
    orchestrator.load_schema("schemas/bpmn/micro_lodging_pipeline.bpmn");

    LodgingJobContextFixed job{
        .bounty_id = "e5f6a9b2-33cc-4e1a-9f01-8c4d2e1f5b6c",
        .nights_count = 4,
        .base_rate_uj = 234000000000000ULL,    // 234000000000000 uJ base stay
        .barter_offset_uj = 86400000000000ULL,  // 86400000000000 uJ timber labor offset
        .estimated_utility_uj = 80640000000000ULL, // 80640000000000 uJ metered power
        .target_suite_id = 1
    };

    // Calculate Net Escrow Lock: Base minus Barter
    uint64_t net_reservation_uj = job.base_rate_uj - job.barter_offset_uj;
    assert(net_reservation_uj == 147600000000000ULL);

    // Execute Stay Simulation (NFC Unlock, Utility Logging, Checkout at 4000 ticks)
    SimResult res = orchestrator.step_simulation_ticks(chunk_mgr, job, 4000);
    assert(res.status == ExecutionStatus::COMPLETED);

    // Settle Ledger with Actual Metered Utility Costs
    uint64_t final_settlement_uj = net_reservation_uj + job.estimated_utility_uj;
    ch_guest_host.balance_u_to_v_uj += final_settlement_uj;
    ch_host_guest.balance_u_to_v_uj -= final_settlement_uj;
    assert(verify_lodging_bcc_conservation(ch_host_guest, ch_guest_host));

    assert(ch_guest_host.balance_u_to_v_uj == 228240000000000LL);
    assert(ch_host_guest.balance_u_to_v_uj == -228240000000000LL);

    // Verify Door Relocked Post-Checkout
    Voxel post_door = chunk_mgr.get_voxel(16, 8, 16);
    assert(post_door.metadata & 0b00000001); // Locked bit remains set
}
```
