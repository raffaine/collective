# Architecture: The 7-Layer Sovereign Stack

The Collective operates on a strict 7-layer hierarchy inspired by the OSI networking model. By isolating physical thermodynamics from semantic human intent, the system prevents the monolithic failures, security exploits, and LLM hallucination risks inherent in legacy platforms. 

## The Strict Traversal Protocol

To maintain cryptographic integrity and physical safety, the engine enforces rigid traversal rules:
* **No Layer Skipping:** A user interface (Layer 6) cannot fire a physical valve (Layer 1). The intent must compile down through policy (L5), state orchestration (L4), network consensus (L3), and the edge broker (L2) before actuating.
* **Downward (Compilation):** Information flowing down the stack translates abstract human intent into deterministic, physical execution.
* **Upward (Abstraction):** Information flowing up the stack translates raw thermodynamic telemetry into human-readable knowledge, semantic proofs, and economic value.
* **The Deterministic Boundary:** Generative AI and LLM agents are strictly confined to Layers 5 and 6. Layers 1 through 4 are mathematically deterministic, running on compiled WebAssembly, C++20, and physical silicon.

## The Stack Breakdown

| Layer | Designation | Core Function | Primary Protocols & Formats |
| :--- | :--- | :--- | :--- |
| **7** | **Legacy Proxy** | Fiat ingestion, legal defense, and legacy API routing. Shields the sovereign node from external state-level and corporate threats. | Stripe API, Legal Trust Deeds, SPC Charters |
| **6** | **Semantic** | Human intent, UI/UX, and long-term decentralized archiving. Formats workflows into verifiable knowledge artifacts. | JSON-LD, Schema.org, PROV-O, IPFS |
| **5** | **Policy** | Polycentric governance, Web of Trust, and permissioning. Evaluates L6 intents against community constraints and reputational weight. | Cryptographic Attestations, Multi-sig Smart Contracts |
| **4** | **Orchestration** | Deterministic automation. Converts approved policies into executable workflows, temporal scheduling, and localized state machines. | BPMN 2.0 XML, Embedded WASM Executor |
| **3** | **Ledger & Network** | Decentralized consensus, CRDT state syncing, and thermodynamic token minting (Proof of Stewardship). The peer-to-peer mesh. | libp2p Gossipsub, CRDTs, Local-First DBs |
| **2** | **Digital Twin** | Edge telemetry and hardware actuation. The immediate digital translation of the physical environment's sensor network. | MQTT, CoAP, JSON payloads via local WiFi/LoRa |
| **1** | **Physical** | Reality. The soil, water, copper, carbon, and caloric labor that form the ultimate, undeniable ground truth of the system. | Joules, Liters, Photons, Human Calories |
