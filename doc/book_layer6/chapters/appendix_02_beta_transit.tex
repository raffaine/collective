\chapter{Appendix 02: Beta Transit}

\section{The Legacy Paradigm \\\& Its Failures}
Legacy transit systems utilized centralized dispatch algorithms that obscured routing logic and extracted value. Users were glued to their mobile devices, constantly refreshing maps that consumed immense battery power and GPU resources, leading to notification fatigue and thermodynamic waste.

\section{The Incremental Automation Pathway}
Phase 1 introduces local-first mesh routing, where transit nodes share schedules via CRDTs. Phase 2 utilizes ambient E-ink signage at transit stops, dynamically updating without centralized cloud pings. Phase 3 enables zero-click transit hailing through spatial presence detection, where the network anticipates demand and routes vehicles automatically.

\section{The Human Boundary (Limits of Automation)}
The system cannot force a routing change that significantly alters a passenger's expected arrival time without explicit consent. If the transit mesh attempts to reroute for thermodynamic efficiency, the interface introduces a cognitive pause, presenting a choice between time and energy consumption.

\section{Interface Mechanics (The "How")}
Thermodynamic rendering is paramount here; mobile devices default to raw text or low-power maps when the local microgrid is strained. Algorithmic triage ensures passengers only receive alerts for critical delays. A missing mechanism is the integration of physical mesh-node handoff indicators for fast-moving vehicles.

\section{Semantic NLP Translation}
Transit users communicate in unstructured, urgent terms: "I need to get to the clinic fast, but I can share a ride." The local, edge-based LLM captures this messy intent and parses it into a strict Layer 5 \texttt{TransitRequestIntent} payload. By querying the local mesh network's CRDT state, the LLM maps "the clinic" to exact spatial coordinates and translates the urgency and sharing preference into a cryptographically sound transit bid, cleanly packaged for the Layer 4 Orchestrator without ever sending personal location data to a cloud provider.
