\subsection{Why Extracting the Companion App Validated Sovereign Separation of Concerns}

Inside \texttt{core/1\_simulation/}, the Oasis WebGPU 3D spatial twin enforces strict constitutional containment: it holds zero Ed25519 signing keys, opens zero external network sockets, and tags every synthetic sensor reading with provenance flag \texttt{QUALITY\_SIMULATED = 0x01} (visually framed with simulation-mode badges distinct from physical \texttt{QUALITY\_HARDWARE\_ROOT = 0x02}). By moving all Layer~6 interactions out of the 3D canvas into \texttt{companion\_l6.js} communicating over HTTP and \texttt{BroadcastChannel} with \texttt{col-gatewayd}, the team proved that \textbf{the exact same Layer~6 application code used during Lot~402 rehearsal can serve as the starter production application for a physical Collective node}.

Six concrete architectural highlights are live and verifiable in the repository today:

\subsubsection{Highlight 1: 100\% Shared Dual-Mount Companion App and Zero-Mock Offline Honesty}
The module \texttt{core/1\_simulation/src/web/js/companion\_l6.js} (lines~1--1482) mounts identically across two execution surfaces without forked UI logic:
\begin{itemize}

    \item as a standalone browser or mobile application served directly by \texttt{col-gatewayd} at \texttt{GET /companion} (\texttt{core/1\_simulation/src/web/companion/index.html}, routed in \texttt{src/daemons/col-gatewayd/gateway\_server.hpp}, lines~1483--1535).
\end{itemize}
Cross-tab state synchronization runs over \texttt{BroadcastChannel('oasis\_daemon\_sync')} inside \texttt{daemon\_client.js} (lines~56--73). Crucially, if \texttt{col-gatewayd} is unreachable, \texttt{companion\_l6.js} (lines~156--161) refuses to invent synthetic client-side mock numbers, surfacing an explicit \texttt{\#l6-offline-banner} until daemon telemetry resumes.

\subsection{Ceiling 1 (Local-First \& Gateway Specialist): 1.5s Full-Snapshot Polling and Single-App Hardcoding}
\textbf{Diagnosis:} \texttt{daemon\_client.js} (line~11) polls the unpaginated endpoint \texttt{GET /api/v1/snapshot} every $1{,}500\,\mathrm{ms}$, invoking \texttt{SerializeFullNodeSnapshotJson()} (\texttt{shared\_stack\_runtime.hpp}, lines~2143--2495) to serialize every layer's state into one monolithic payload. On each tick, \texttt{companion\_l6.js} (lines~444--478) runs \texttt{JSON.stringify} dirty checks and overwrites \texttt{innerHTML} across all four tabs---even hidden ones---resetting unfocused scroll positions and \texttt{<details>} disclosures while burning mobile CPU/battery. Moreover, the four tabs are hardcoded inside one script rather than capability-scoped per application.

\textbf{v3.1 Remedy:} Replace snapshot polling with topic-scoped WebSocket/SSE delta streams (\texttt{/ws/v1/subscribe?topics=hearth.*}) emitting RFC~6902 JSON-Patch / CBOR frames keyed by monotonic HLC cursors, surgical keyed DOM patching on active views only, and declarative \texttt{AppCapabilityManifestV1} registration so specialized Constellation apps subscribe strictly to their domain slice.

\subsection{Ceiling 2 (Cryptographic Authorship Specialist): Unsigned Mutations and Post-Hoc Read-Back}
\textbf{Diagnosis:} \texttt{daemon\_client.js} (lines~252--271) dispatches plaintext \texttt{POST /api/v1/command} payloads without cryptographic signatures; \texttt{companion\_l6.js} (line~558) populates \texttt{requester\_did} from an unverified string; \texttt{gateway\_server.hpp} (lines~1360--1416) zeroes out \texttt{ed25519\_signature} when constructing internal envelopes while leaving \texttt{did\_auth\_required} (\texttt{col-gatewayd/main.cpp}, line~63) unenforced; zero \texttt{crypto.subtle} (\texttt{extractable: false}) IndexedDB keys exist yet; \texttt{plain\_language\_read\_back} (\texttt{gateway\_server.hpp}, line~1425) is returned \textit{after} state mutation rather than gating signature before mutation; and the four provenance tags (\texttt{human\_authored}, \texttt{machine\_drafted\_human\_approved}, \texttt{machine\_generated}, \texttt{system\_authenticated}) are absent from wire structs.

\textbf{v3.1 Remedy:} Split mutation into a mandatory two-phase protocol: \texttt{POST /api/v1/intent/compile} returns the canonical \texttt{Intent\_CID}, fixed-template \texttt{deterministic\_read\_back} prose, and \texttt{TextProvenance} tag; only after the user holds a $500\,\mathrm{ms}$ confirmation gesture does Web Crypto (\texttt{extractable: false}) or \texttt{ATECC608A} sign $\mathrm{SHA256}(\texttt{"COL-INTENT-V3.1\textbackslash0"} \,\|\, \texttt{Intent\_CID} \,\|\, \texttt{read\_back\_hash})$ for \texttt{POST /api/v1/intent/commit}, verified strictly by \texttt{col-kmsd} across \texttt{l5\_l6.sock}.

\subsection{Ceiling 3 (Semantic Web Architect): Substring Stubs, Floats, IRI Drift, and \texttt{Treaty\_CID} Collision}
\textbf{Diagnosis:} \texttt{JsonLdIntent::ParseStub} (\texttt{col-commonsd/main.cpp}, lines~206--219) parses JSON-LD via brittle \texttt{std::string::find()} substring checks while \texttt{gateway\_server.hpp} (line~1372) truncates \texttt{payload\_jsonld[128]} at $127\,\mathrm{bytes}$; \texttt{col-commonsd/main.cpp} (lines~203, 229--239) and \texttt{pea\_to\_soup\_needs.jsonld} (line~35, \texttt{4.68 MJ}) admit floating-point numbers; three divergent \texttt{@context} IRIs coexist; and \texttt{RicardianTreaty::ComputeCID()} (\texttt{col-commonsd/main.cpp}, lines~178--187) concatenates \texttt{legal\_prose + "|" + jsonld\_schema + "|" + bpmn\_invariants} without byte-length framing.

\textbf{v3.1 Remedy:} Enforce the unified offline \texttt{https://w3id.org/collective/v1/} context registry, replace \texttt{ParseStub} and $128$-byte truncation with streaming arena-backed JSON-LD~1.1 expansion + W3C \texttt{RDFC-1.0} and \texttt{RFC 8785 JCS} canonicalization, frame all \texttt{Treaty\_CID} components with 64-bit big-endian lengths (Equation~\ref{eq:length-prefixed-cid}), and convert all quantities to \texttt{int64\_t} / \texttt{uint64\_t} fixed-point SI units (\texttt{4680000000000 uJ}).

\subsection{Ceiling 4 (Legal Carapace Counsel): Legacy Statutory Currency Bleed Across Layer~6 and Layer~3}
\textbf{Diagnosis:} \texttt{companion\_l6.js} formats legacy statutory currency cents across all four Layer~6 tabs (lines~13, 55--59, 200, 495, 694, 833, 1121, and 1354), and \texttt{L3NodeLedger} (\texttt{shared\_stack\_runtime.hpp}, lines~852--864) embeds \texttt{household\_reserve\_cents} and \texttt{monthly\_legacy\_bills\_cents} directly inside a Layer~3 thermodynamic struct. Exposing statutory currency figures across daily Layer~6 civic views subtly re-anchors human cognition around external market pricing instead of physical microjoules, milligrams, and unconditional $R_0$ care.

\textbf{v3.1 Remedy:} Purge all statutory currency fields from \texttt{L3NodeLedger} and general Layer~6 Constellation views (Hearth, Garden, Workshop, Care, and Agora surfaces render exclusively physical SI quantities and pairwise zero-sum \texttt{BCC} credits with \texttt{domestic\_care\_token\_minting == 0}). Quarantine statutory tax, utility-bill, and Subchapter~T reserve accounting strictly inside a dedicated, role-gated \textbf{Layer~7 Carapace Fiduciary App} (\texttt{carapace:fiduciary}) communicating across \texttt{l6\_l7.sock}.

\subsection{Ceiling 5 (Gateway \& IPC Engineer): In-Process Runtime, Wildcard CORS, and Dropped Offline Intents}
\textbf{Diagnosis:} \texttt{GatewayServer} (\texttt{gateway\_server.hpp}, line~1553) embeds a private \texttt{SharedStackRuntime} instance in-process rather than speaking over \texttt{AF\_UNIX} \texttt{SOCK\_SEQPACKET} sockets to separate daemons; \texttt{col-commonsd/main.cpp} (lines~315--327) runs a standalone loop without binding \texttt{l5\_l6.sock} or \texttt{l6\_l7.sock}; \texttt{gateway\_server.hpp} binds \texttt{0.0.0.0:8090} in plaintext with \texttt{Access-Control-Allow-Origin: *} (lines~245, 717) and unauthenticated \texttt{/api/v1/l2\_pins} mutation hooks (line~675); and \texttt{daemon\_client.js} (lines~267--270) drops mutations on network failure rather than queuing them offline.

\textbf{v3.1 Remedy:} Bind \texttt{col-commonsd} strictly to \texttt{/run/collective/ipc/l5\_l6.sock} and \texttt{/run/collective/ipc/l6\_l7.sock} with \texttt{SO\_PEERCRED} UID/PID verification; restrict physical \texttt{/api/v1/l2\_pins} injection exclusively to \texttt{0x01} SITL test builds; pin \texttt{col-gatewayd} to VLAN~30 TLS~1.3 origin allowlists; and persist offline mutations in an IndexedDB \textbf{Domain~B Automerge CRDT Outbox} carrying monotonic \texttt{X-Collective-Sequence} and \texttt{X-Collective-Dependency-Vector} headers.

\subsection{Ceiling 6 (Adversarial ML Auditor): Missing Dual-Sandbox Edge NLU and Exergy Shedding}
\textbf{Diagnosis:} Neither \texttt{col-commonsd} nor \texttt{col-gatewayd} yet implements process-isolated Intake vs.\ Drafting language-model sandboxes, finite-state grammar-constrained slot extraction, SHA-256 model-weight attestation, or microjoule (\texttt{uJ}) inference load shedding.

\textbf{v3.1 Remedy:} Spawn two unprivileged Linux namespace workers under \texttt{col-commonsd}---\texttt{col-nlu-intake} (zero L5 schema/user-history visibility, Outlines/GBNF FSM-constrained scalar slot pipe for untrusted \texttt{l6\_l7.sock} documents) and \texttt{col-nlu-draft} (authenticated human input only, zero raw L7 text)---governed by Layer-5-ratified SHA-256 weight manifests and gated by \texttt{SoC\_bp} battery thresholds.

\subsection{Ceiling 7 (Calm HCI \& Accessibility Specialist): Sub-10px CSS, Missing Refusal Control, and Flat Lists}
\textbf{Diagnosis:} \texttt{oasis.css} hardcodes $8.5\text{--}9.5\,\mathrm{px}$ font sizes (lines~144, 355, 456, 1029), $< 24\,\mathrm{px}$ action buttons (lines~291, 349, 964), \texttt{outline: none} (line~943), and $\approx 5.6:1$ muted contrast (\texttt{\#94a3b8} on \texttt{\#0f172a}); \texttt{companion\_l6.js} (lines~146--151) omits WAI-ARIA \texttt{tablist}/\texttt{tabpanel} roving keyboard focus; \texttt{hud\_feel.js} (lines~771--809) lacks a guilt-free \texttt{Step Back / Unclaim} button once a task is committed; print/voice/E-Ink stylesheets are absent; and Tab~3 renders flat workflow rows rather than spatially coalesced Homestead Rounds.

\textbf{v3.1 Remedy:} Ship the WCAG~2.2~AAA fluid \texttt{rem} / $\ge 7:1$ / $\ge 48\,\mathrm{px}$ token stylesheet (Chapter~\ref{ch:thermodynamic-accessibility}) alongside \texttt{@media print} QR batch travelers and E-Ink themes, wire \texttt{UNCLAIM\_GUILT\_FREE} and \texttt{RestShield} controls into every task card, and group \texttt{WAITING\_HUMAN} tokens via the Spatial Homestead Round Coalescer (Chapter~\ref{ch:cognitive-triage}).

\section{Four-Milestone Engineering Roadmap to Full Constellation Sovereignty}
\label{sec:constellation-roadmap}

To transition cleanly from the working Lot~402 starter Companion App to a multi-surface bioregional deployment without breaking live simulation tests, the Council ratified a four-milestone incremental roadmap:

\begin{enumerate}
    \item \textbf{Milestone M1 --- Semantic \& Ergonomic Hygiene on the Starter App:} Unify \texttt{@context} mappings under offline \texttt{https://w3id.org/collective/v1/}, eliminate the remaining float literal in \texttt{pea\_to\_soup\_needs.jsonld} and float fields in \texttt{col-commonsd}, upgrade \texttt{oasis.css} and \texttt{companion\_l6.js} to WCAG~2.2~AAA contrast/sizing/ARIA compliance, add the one-tap \texttt{UNCLAIM\_GUILT\_FREE} / \texttt{RestShield} control, and segregate Layer~7 statutory bill figures out of \texttt{L3NodeLedger} into a dedicated L7 Carapace view.
    \item \textbf{Milestone M2 --- True \texttt{SOCK\_SEQPACKET} Daemon Split \& Two-Phase Hardware Signing:} Decouple \texttt{GatewayServer} from in-process \texttt{SharedStackRuntime} by activating \texttt{/run/collective/ipc/l5\_l6.sock} and \texttt{l6\_l7.sock} with \texttt{SO\_PEERCRED} enforcement, implement two-phase \texttt{Compile -> Deterministic Read-Back -> Web Crypto / ATECC608A Ed25519 Sign}, and lock \texttt{/api/v1/l2\_pins} strictly behind \texttt{0x01} simulation build guards.
    \item \textbf{Milestone M3 --- Delta Streams, Domain~B Automerge Outbox \& First Specialized Constellation Slates:} Replace $1.5\,\mathrm{s}$ full-snapshot polling with \texttt{/ws/v1} topic delta patches and IndexedDB Automerge CRDT offline queuing; extract the first four dedicated Constellation clients sharing the Uniform Semantic Foundation (\textit{Hearth \& Pantry E-Ink Slate}, \textit{Agroecology Cultivar Fieldbook}, \textit{Shop-Floor BOM Terminal}, and \textit{Cargo-Trike Offline Courier Deck}) alongside printable QR batch travelers.
    \item \textbf{Milestone M4 --- Dual-Sandbox Edge NLU, Spatial Round Coalescer \& Screenless Assembly Suite:} Deploy \texttt{col-nlu-intake} (GBNF/FSM slot pipe) and \texttt{col-nlu-draft} with SHA-256 weight governance and \texttt{SoC\_bp} load shedding, activate Spatial Homestead Round Coalescing across $100+$ concurrent workflows, and certify Helios verifiable paper ballots, offline voice read-back loops, and hardware-severed Unmediated Space latches.
\end{enumerate}
