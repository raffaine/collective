Every human-facing software layer encodes an implicit constitution. In conventional enterprise,
civic, and smart-infrastructure platforms, that constitution is overwhelmingly centralizing: a
single monolithic web portal or mobile ``super-app'' accumulates presentation code, domain rules,
session credentials, behavioral analytics, direct database write paths, and actuator overrides
behind one administrative screen. What begins during early prototyping as developer convenience
hardens rapidly into both a security hazard and a cognitive bottleneck. A single compromised
client context or misconfigured API route acquires simultaneous visibility into intimate
household routines and unmediated authority over physical infrastructure
\parencite{saltzer1984end,rose2020zero,zuboff2019}. Worse still, when an entire community's
activities are funneled through one generalist dashboard, people must mentally translate their
situated physical craft---cooking, farming, machining, caregiving, or deliberating---into the
rigid schema of an engineering control panel \parencite{illich1973,costanzachock2020design}.

To avoid that trap permanently, Version~3.2 opens with a foundational architectural analogy:

\begin{quote}
\textbf{The HTTP Protocol Analogy for Layer~6:} Just as HTTP is not ``one giant website to rule
them all,'' but a shared application-layer protocol over which millions of independent applications
operate, \textbf{Layer~6 is not a monolithic super-app or single operating-system shell}. Layer~6 is
a \textbf{semantic protocol and compilation/decompilation boundary}. A single local \textbf{Layer~6
Semantic Daemon} (\texttt{col-commonsd} paired with \texttt{col-gatewayd} on VLAN~30 TLS~1.3
\texttt{:8443}) maintains the node's sovereign W3C JSON-LD~1.1 Ontological Graph
($\mathcal{G}_{\mathrm{surface}}$) and communicates strictly downward to Layer~5
(\texttt{col-kmsd} over \texttt{/run/collective/ipc/l5\_l6.sock}) and outward to Layer~7
(\texttt{col-adversaryd} over \texttt{/run/collective/ipc/l6\_l7.sock}), while an open-ended
\textbf{Constellation of Specialized Application Lenses}
($\mathcal{L}_a : \mathcal{G}_{\mathrm{surface}} \to \mathcal{V}_a$) sits on top.
\end{quote}

Because \textbf{Layer~6: The Semantic Commonwealth} is the most visible layer of the Sovereign
Stack---the surface that almost every resident, visitor, neighbour, and third-party application
developer interacts with directly---this HTTP-like separation enforces three structural guarantees:

\begin{enumerate}
\item \textbf{Single Downward Semantic Conduit and Bilateral Socket Containment:} Application
      Lenses never open sockets directly to Layer~5 (\texttt{col-kmsd}), Layer~4
      (\texttt{col-execd} / \texttt{col-swarmd}), Layer~3 (\texttt{col-storaged} /
      \texttt{col-meshd}), or Layer~2 (\texttt{col-telemetryd}). Every lens speaks exclusively to
      the local Layer~6 Semantic Daemon (\texttt{col-gatewayd} + \texttt{col-commonsd}), which
      validates the lens's \texttt{AppCapabilityToken}, normalizes localized human units into
      64-bit fixed-point SI integers, canonicalizes JSON-LD intents via \texttt{RDFC-1.0} and
      \texttt{RFC 8785 JCS}, verifies Stage~4 Deterministic Read-Back digest binding, and routes
      signed frames across two kernel-authenticated \texttt{AF\_UNIX} \texttt{SOCK\_SEQPACKET}
      membranes: inward across \texttt{l5\_l6.sock} and outward across \texttt{l6\_l7.sock}.
\item \textbf{Multi-Node Routing Below One Local Semantic Daemon:} Rejecting modernist monoculture
      zoning (``a building is \textit{either} a home \textit{or} an office \textit{or} a shop''),
      Layer~5 institutional topology is decoupled from Layer~2 spatial coordinates. One physical
      building can simultaneously host a Household Hearth ($N_s=4$), a Solo Studio ($N_s=1$), and a
      Maker Bench ($N_s=1$) wrapped by a domain-blind \textbf{Enveloping Node Hypervisor}. All
      Application Lenses on the steward's devices still talk to the \textbf{single local Layer~6
      Semantic Daemon}, which routes each signed intent downward through the matching Layer~5 node
      namespace in \texttt{col-kmsd}.
\item \textbf{Zero-Stat Liberation Against the Attention Economy:} Layer~7 commercial platforms
      maximize ``time-on-screen'' through infinite scroll, variable-ratio notifications, and
      gamified progress bars. Layer~6 Application Lenses are engineered for \textbf{Zero-Stat
      Liberation}: there are zero fake RPG stat buffs (no ``$+25\%$ cooking speed'' unlock), zero
      engagement leaderboards, and every routine lens interaction is designed to complete in under
      $30$~seconds---getting the human out of the application and back to the physical hearth,
      workshop bench, or unmediated dining table as quickly as possible.
\end{enumerate}

\subsection{The Read-Only Diagnostic Hood and HTTP \texttt{405} Enforcement}

While Layer~6 is forbidden from mutating lower layers directly, human stewards and specialized
Application Lenses need transparent, calm observability into the underlying cybernetic state:
whether an automated drip-irrigation valve in Layer~2 is open, whether Layer~3 mutual-credit
channels and Ecological Replacement Cost ($\lambda_{\mathrm{ERC}}$) ledgers are balanced, or where
a BPMN~2.0 token in Layer~4 is currently executing a Tier~1 SI parameter scaling step. To provide
this observability without introducing mutating backdoors, \texttt{col-gatewayd} maps lock-free
Single-Producer Single-Consumer (\texttt{SPSC}) shared-memory telemetry rings in strictly
read-only consumer mode and exposes diagnostic \texttt{GET} projections under
\texttt{/api/telemetry} and \texttt{/api/v1/l1/*} through \texttt{/api/v1/l7/*}.

In \texttt{GatewayServer::HandleRequest()} (\texttt{src/daemons/col-gatewayd/gateway\_server.hpp}),
any attempt by an application lens, script, or compromised browser tab to issue a mutating HTTP
verb (\texttt{POST}, \texttt{PUT}, \texttt{PATCH}, or \texttt{DELETE}) against
\texttt{/api/telemetry} or any lower-layer diagnostic namespace is intercepted by
\texttt{IsDiagnosticLayerPath()} and rejected with an explicit
\texttt{HTTP 405 Method Not Allowed} response and \texttt{Allow: GET, OPTIONS} header:
\begin{equation}
\begin{aligned}
\forall m \in \{\texttt{POST}, \texttt{PUT}, \texttt{PATCH}, \texttt{DELETE}\}, \quad
\forall p \in \{\texttt{/api/telemetry}, \; \texttt{/api/v1/l}k\texttt{/*} \mid k \in \{1..5, 7\}\}: \\
\mathrm{Gateway}(m, p) \longrightarrow \texttt{HTTP 405 Method Not Allowed}
\; (\texttt{READ\_ONLY\_NO\_DIRECT\_MUTATIONS})
\end{aligned}
\end{equation}

Every human decision enters exclusively through the Layer~6 lens endpoints
(\texttt{/api/l6/v1/*} and \texttt{/api/v1/intent/*}) as a canonical, human-signed JSON-LD
semantic intent after passing Stage~4 Deterministic Read-Back.

\section{Layer 6 as the Wide-Purpose Semantic Surface Over Cybernetic Reality}
\label{sec:ch1-semantic-surface}

Why must Layer~6 exist as a dedicated local Semantic Daemon (\texttt{col-commonsd} +
\texttt{col-gatewayd}) rather than letting user interfaces query Layer~3 storage or Layer~4
workflow tables directly? Because the data structures required for deterministic real-time
cybernetics are fundamentally different from the conceptual structures required for human
understanding, pluralistic deliberation, and open-ended application development
\parencite{gruber1993ontology,winograd1986understanding}.

\subsection{The Semantic Surface Lifting Operator ($\Pi_{\mathrm{up}}$) and Lens Projection ($\mathcal{L}_a$)}

Consider what exists underneath Layer~6 at any instant $t$:
\begin{equation}
    \mathcal{S}_{\mathrm{cyber}}(t) = \bigl\langle \mathbf{T}_{\mathrm{L2}}(t),\; \mathbf{L}_{\mathrm{L3}}(t),\; \mathbf{W}_{\mathrm{L4}}(t),\; \mathbf{G}_{\mathrm{L5}}(t) \bigr\rangle

where $\mathbf{T}_{\mathrm{L2}}(t)$ is the vector of 64-bit fixed-point SI transducer samples in

Ecological Replacement Cost ($\lambda_{\mathrm{ERC}}$) registry, and anonymous appetite lease
table, $\mathbf{W}_{\mathrm{L4}}(t)$ is the active table of Wasmtime BPMN~2.0 token positions and
3-tier hardware adaptation states, and $\mathbf{G}_{\mathrm{L5}}(t)$ is the set of Four-Pillar
node constitutions, $V_i(t)=1+R_i(t)$ member voice states, Enveloping Node boundary leases, and
blinded task claim handles.

If an application developer had to parse $\mathcal{S}_{\mathrm{cyber}}(t)$ directly, every user

\begin{equation}
    \mathcal{G}_{\mathrm{surface}}(t) = \Pi_{\mathrm{up}}\!\bigl(\mathcal{S}_{\mathrm{cyber}}(t),\; \mathcal{O}_{\mathrm{libraries}}\bigr)

Joining live lower-layer states $\mathcal{S}_{\mathrm{cyber}}(t)$ against the node's Three
Sovereign Content-Addressed JSON-LD Libraries $\mathcal{O}_{\mathrm{libraries}}$ (\textit{The
Ontological Graph}, \textit{The Orchestration Registry}, and \textit{The Physics Baseline}),

          multiplier. Instead, its real physical penalties vanish: parasitic Layer~2 shim watt
          drain drops to zero, Layer~7 fiat spare-part tribute drops to zero, and unannounced blind
          mid-batch breakdowns are replaced by quiet, predictable 5-minute metric part swaps

          measured by how \emph{little} time a steward spends staring at it. Whether tapping an NFC
          tiffin carrier at \textit{The Bakery}, glancing at an Arrhenius TTL bar in \textit{The

\subsection{The Five-Part Layer~6 Application Lens Developer Contract}

\subsection{VLAN 30 TLS 1.3 (\texttt{:8443}) and \texttt{\#pair\_token} URI-Fragment QR Pairing}

To pair a new Application Lens without cloud identity providers, certificate-authority lock-in,
or password databases, \texttt{col-gatewayd} binds its listener strictly to local Civic
VLAN~30 (\texttt{:8443}) and advertises \texttt{\_collective-l6.\_tcp.local} via mDNS alongside
its SPKI SHA-256 certificate fingerprint. A steward displays a 60-second, single-use 256-bit
pairing QR code on an already-authenticated screen or E-Ink node faceplate:
\begin{center}
\small\texttt{https://node01.collective.local:8443/lens/\#pair\_token=<base64url\_256b>\&spki=<sha256>}
\end{center}
Placing \texttt{pair\_token} after the \texttt{\#} URI fragment delimiter exploits RFC~3986:
user agents strip the fragment locally and \textbf{never transmit it over the wire} in HTTP
request lines, \texttt{Referer} headers, or access logs. The client reads
\texttt{window.location.hash}, scrubs the URL bar via \texttt{history.replaceState()}, generates
a fresh \texttt{extractable: false} \texttt{Ed25519} keypair in IndexedDB, and completes an
HMAC-SHA256 challenge-response binding its new \texttt{did:peer} key and
\texttt{AppCapabilityManifestV1} CID over TLS~1.3.

\subsection{1:1 Lock-Free SPSC Shared Memory Rings (\texttt{/uhai\_telemetry\_gateway})}

If twenty Application Lenses subscribe to live semantic deltas over courtyard Wi-Fi, TCP socket
backpressure in \texttt{col-gatewayd} must never stall \texttt{col-commonsd}'s semantic compiler
loop or \texttt{col-telemetryd}'s deterministic sensor loop. As implemented in
\texttt{uhai\_ring\_buffer.hpp} and \texttt{GatewayServer::PollRingBuffers()}, the stack
decouples gateway readers via dedicated 1:1 Lock-Free Single-Producer Single-Consumer
(\texttt{SPSC}) POSIX shared-memory segments (\texttt{"/uhai\_telemetry\_gateway"}):
\begin{itemize}
\item \textbf{False-Sharing Elimination Across Three 64-Byte Cache Lines:} The 192-byte
      \texttt{SharedRingHeader} isolates the producer's \texttt{write\_index} and atomic
      \texttt{dropped\_frames} counter in Cache Line~0 (\texttt{0..63}), the consumer's
      \texttt{read\_index} in Cache Line~1 (\texttt{64..127}), and immutable ring geometry
      (\texttt{RING\_CAPACITY = 1024}, \texttt{UHAI\_MAGIC = 0x55484149}) in Cache Line~2
      (\texttt{128..191}).
\item \textbf{Wait-Free Overrun Safety and Pure Fixed-Point SI Slots:} Combined with
      $1{,}024 \times 64$-byte cache-aligned \texttt{TelemetrySlot} entries ($65{,}728$~bytes
      total, strictly free of IEEE-754 floats), any transient HTTP backpressure simply increments
      \texttt{dropped\_frames} with \texttt{memory\_order\_relaxed} in $O(1)$ nanoseconds while
      \texttt{col-gatewayd} drains the freshest state on its next poll cycle.
\end{itemize}
