\chapter{The Bioregional Agora, Ricardian Treaties, and Mundane Semantic Camouflage}
\label{ch:agora-treaties}

\epigraph{Polycentric systems tend to enhance innovation, learning, adaptation, trustworthiness, levels of cooperation of participants, and the achievement of more effective, equitable, and sustainable outcomes at multiple scales.}{--- Elinor Ostrom, \emph{Beyond Markets and States: Polycentric Governance of Complex Economic Systems} \parencite{ostrom2010}}

No single homestead or neighborhood settlement is an island of ecological or industrial self-sufficiency. A resilient community on a half-hectare parcel can cultivate perennial legumes, steward closed-loop compost, and balance a rooftop $48\,\mathrm{V}$ microgrid, yet it cannot smelt specialty bearing steel, fabricate silicon photovoltaics, run a tertiary trauma theater, or govern an entire river basin alone \parencite{ostrom1990,georgescu1971}. Conversely, history demonstrates the twin hazards that destroy local autonomy whenever settlements federate carelessly: either horizontal coordination collapses into price-mediated commodity markets that financialize domestic care and exhaust regional watersheds \parencite{raworth2017,han2015}, or unconventional mutual-aid institutions announce themselves in flamboyant ideological vocabulary that invites immediate regulatory, tax, and liturgical encirclement by legacy state and corporate bureaucracies \parencite{scott1998}.

Layer~6 resolves both hazards inside the \texttt{col-commonsd} daemon. Across the inward socket boundary (\texttt{/run/collective/ipc/l5\_l6.sock}), \texttt{col-commonsd} convenes the \textbf{Bioregional Agora}: a calm, non-gamified deliberative commons spanning seven concentric Trust Rings ($R_0 \dots R_6$), pairing sortition Citizens' Assemblies, Future Generations ecological panels, and dissent-preserving argument maps with a pure 64-bit integer Continuous Double-Auction (\texttt{CDA}) for industrial and ecological surpluses. Across the outward socket boundary (\texttt{/run/collective/ipc/l6\_l7.sock}), \texttt{col-commonsd} compiles ratified inter-settlement pacts into cryptographically immutable \textbf{Ricardian Inter-Node Treaties} \parencite{grigg2004} while passing every legacy-bound directive through the \textbf{Mundane Semantic Camouflage Filter}. By wrapping inter-node physical flows inside conventional cooperative statutes and ensuring that zero bytes of internal Decentralized Identifiers (\texttt{DID}s), ballots, or Web-of-Trust edges ever cross into Layer~7, the Semantic Commonwealth achieves polycentric regional scale alongside constitutional subpoena immunity through architectural data non-existence \parencite{naacp1958}.

\section{Deliberative Formats Across Concentric Trust Rings ($R_0 \dots R_6$)}

In conventional social platforms, civic discourse is flattened into a single global engagement feed ranked by outrage velocity, follower counts, and algorithmic amplification \parencite{zuboff2019,gray2018darkpatterns}. Such architectures violate Stafford Beer's Law of Requisite Variety \parencite{beer1972,ashby1956}: intimate household decisions are over-exposed to strangers, while bioregional watershed trade-offs drown in performative noise. Following Elinor Ostrom's design principles for nested enterprises \parencite{ostrom1990,ostrom2010}, Layer~6 structures deliberation across seven concentric Trust Rings ($R_0$ through $R_6$) enforced cryptographically by Layer~5 (\texttt{col-kmsd}) and rendered contextually across specialized Constellation applications.

Rather than forcing every collective question through adversarial majority-rule voting, the Agora equips stewards with four complementary deliberative institutions tailored to the epistemic character of each decision:

\begin{enumerate}
  \item \textbf{Unitary Hearth Assemblies and Structured Argument Maps ($R_1 \dots R_4$):} Drawing on Jane Mansbridge's distinction between unitary democracy among face-to-face equals and adversary procedures across divergent interests \parencite{mansbridge1980}, local $R_1$ assemblies deliberate toward high-consensus synthesis first, escalating to formal bicameral supermajority ballots ($50\%$, $66\%$, or $80\%$ constitutional thresholds) only when trade-offs persist. Following J\"{u}rgen Habermas's discourse ethics \parencite{habermas1996between}, \texttt{col-commonsd} renders contested proposals as side-by-side structured argument maps linking every factual claim to content-addressed Layer~3 telemetry or archival evidence (\texttt{CID}s) rather than chronological comment threads that reward the loudest or most persistent speaker \parencite{freeman1972}.
  \item \textbf{Sortition Citizens' Assemblies ($R_2 \dots R_5$):} When technical or distributional questions affect dozens of settlements---such as reallocating dry-season irrigation quotas or siting a shared induction foundry---\texttt{col-kmsd} and \texttt{col-commonsd} convene deliberative minipublics selected by verifiable cryptographic sortition \parencite{fishkin1991}. Stratified random sampling across affected nodes prevents entrenched political classes or informal elites from capturing regional agendas \parencite{freeman1972}, giving rotating cohorts paid exergy/chore relief time to hear agronomic testimony and draft balanced policy options.
  \item \textbf{Future Generations Ecological Panels ($R_1 \dots R_6$):} Inspired by statutory intergenerational stewardship mandates \parencite{wales2015future} and biophysical Doughnut boundaries \parencite{raworth2017}, every proposal that alters watershed extraction, soil organic carbon trajectories, or long-lived infrastructure must pass review by a standing Future Generations panel. Armed with deterministic Oasis (\texttt{Layer 1b}) multi-decade foresight runs, the panel holds suspensive veto authority whenever projected Asymptotic Ecological Replacement Cost ($\lambda_{\mathrm{ERC}}$) exceeds regenerative recharge thresholds.
  \item \textbf{Restorative Review Councils ($R_1 \dots R_3$):} Conflict, covenant breach, and interpersonal harm within or between nodes are never adjudicated through public shaming boards or automated algorithmic penalties. Grounded in Howard Zehr's restorative justice framework \parencite{zehr1990}, Review Councils convene affected parties and sortition peers in confidential circles focused on naming concrete harm, repairing material balances, and restoring relational standing while preserving every participant's unconditional survival floor.
\end{enumerate}

\subsection{Dissent-Preserving Rationale Schemas and Machine Restraint}

Language models within the Agora operate strictly as bounded clerical instruments---transcribing multilingual speech, retrieving cited Layer~3 series, and formatting structured minutes---never as rhetorical arbiters \parencite{bender2021parrots}. Whenever an assembly concludes deliberation, \texttt{col-commonsd} compiles a candidate \texttt{DeliberationRationaleV1} JSON-LD document subject to four hard constitutional constraints:

\begin{enumerate}
  \item \textbf{Tripartite Structural Separation:} Every generated summary must partition propositions into three disjoint arrays---\texttt{consensus\_points}, \texttt{majority\_arguments}, and \texttt{minority\_dissents}---anchoring each statement to explicit transcript span hashes or Layer~3 telemetry \texttt{CID}s.
  \item \textbf{Mandatory Dissenter Co-Signature:} A machine-drafted or clerk-drafted summary \emph{cannot} enter Layer~5's immutable governance log until representatives of each recorded perspective cryptographically sign their respective sections. In particular, every entry in \texttt{minority\_dissents} requires an explicit Ed25519 or BBS+ co-signature from the dissenting steward(s) confirming that their objection has been steel-manned faithfully rather than caricatured by the majority.
  \item \textbf{Zero Ranking or Vote Recommendation:} Grammar-constrained decoding inside \texttt{col-commonsd} strips comparative evaluative adjectives, scalar argument scores, and prescriptive ballot recommendations.
  \item \textbf{Immutable Provenance Tagging and Unmediated Override:} Every machine-summarized field carries \texttt{provenance = MACHINE\_DRAFTED\_HUMAN\_APPROVED} (or \texttt{MACHINE\_GENERATED} while awaiting review). Moreover, any council or assembly may invoke an \textbf{Unmediated Space} or the \textbf{Protocol of Refusal} \parencite{hirschman1970,costanzachock2020design}: hardware microphone ingestion, speech-to-text, LLM summarization, and vector indexing are physically disabled in \texttt{col-commonsd}, ensuring sacred cultural knowledge, intimate restorative circles, and sensitive habitat coordinates remain wholly off-ledger.
\end{enumerate}

\subsection{Anti-Panopticon Rendering, DTN Asynchronous Mesh, and Commons Jubilees}

To prevent civic participation from mutating into surveillance or conformity pressure, Layer~6 enforces strict asymmetric visibility. Each steward's personal Constellation slate displays their own standing, active delegations, and verifiable open-audit ballot receipts \parencite{adida2008helios,juels2005coercion}; public Agora views render \emph{only} ratified proposals, co-signed rationale records, aggregate participation basis points, and anonymized tally totals. \texttt{col-commonsd} refuses to construct, query, or render global reputation leaderboards, contributor rankings, or social graphs revealing who vouched for, delegated to, or voted alongside whom.

Across outer Trust Rings ($R_3 \dots R_6$), settlements communicate over directional LoRa radios, Reticulum packet links, and cargo-trike sneakernet couriers where round-trip latencies span hours or days \parencite{fall2003}. Rather than assuming synchronous TCP sessions, Bioregional Agora deliberations propagate as delay-tolerant, content-addressed Automerge CRDT bundles \parencite{kleppmann2017automerge,shapiro2011crdt} stamped with Hybrid Logical Clocks (\texttt{HLC}) \parencite{kulkarni2014logical,lamport1978time}. Deliberation windows stay open for $14$ to $42$ days so upstream mountain nodes and downstream estuarine nodes contribute empirical testimony without real-time connectivity bias.

Finally, because microclimates, soil parent material, and solar insolation vary unevenly across a bioregion, honest bilateral exchange over multiple seasons can accumulate structural net credit imbalances---for example, a shaded canyon timber guild consistently importing winter calories from a sun-drenched alluvial plain. Rather than compounding interest or enforcing austerity extraction, $R_3$ and $R_4$ assemblies convene seasonal \textbf{Commons Jubilees} \parencite{ostrom1990,kropotkin1902}. During a ratified Jubilee, sister nodes inspect aggregate ecological telemetry, distinguish bad-faith covenant neglect from structural geographic asymmetry, and co-sign a multilateral balance reset toward zero across Layer~3 Bilateral Clearing Channels (\texttt{BCC}s), converting unpayable structural deficits into acknowledged bioregional stewardship investments.

\begin{invariant}[Dissent Co-Signature and Anti-Leaderboard Privacy]
\label{inv:dissent-and-privacy}
Let $\mathcal{R}$ be any Layer~5 \texttt{DeliberationRationaleV1} artifact containing minority dissent set $D = \{d_1, \dots, d_m\}$, and let $\mathcal{V}_{\mathrm{pub}}$ be the set of public views emitted by \texttt{col-commonsd}. (i)~$\mathcal{R}$ is accepted across \texttt{l5\_l6.sock} if and only if every $d_j \in D$ carries a valid signature $\sigma_j$ from its authoring dissenter handle; and (ii)~no view $v \in \mathcal{V}_{\mathrm{pub}}$ ever projects pairwise trust edges $(u, w) \in E_{\mathrm{WoT}}$, delegation targets, or ordinal rankings of individual Reputational Wealth.

\section{Pure-Integer Exergy Agora Clearing and Strict Care Non-Commensurability}
\label{sec:agora-cda-clearing}

While everyday subsistence within $R_0$ and $R_1$ coordinates through voluntary Commons Pool pull and unpriced mutual aid, specialized surpluses exchanged across $R_2 \dots R_4$---such as kiln-dried joinery timber, cold-pressed oilseed, CNC replacement gears, or daytime microgrid export---benefit from transparent supply-and-demand discovery. In \texttt{col-commonsd}, this discovery is performed by a bounded \textbf{Continuous Double-Auction (\texttt{CDA})} \parencite{smith1962experimental} anchored in Nicholas Georgescu-Roegen's thermodynamic economics \parencite{georgescu1971}: bids and asks are denominated in embodied physical exergy rather than arbitrary fiat currency or speculative global tokens.

\subsection{Strict Care Non-Commensurability (\texttt{domestic\_care\_token\_minting == 0})}

The most consequential boundary in Layer~6 economics is what the Agora \emph{refuses} to price. When cooperative experiments attempt to log, price, or auction domestic cooking, infant care, elder accompaniment, grief support, mentorship, or emergency clinical triage on the same ledger as sheet metal and kilowatt-hours, intrinsic kinship solidarity rapidly corrodes into transactional score-keeping \parencite{illich1973,han2015} while simultaneously risking commercial wage-and-tax reclassification under legacy labor statutes \parencite{alamo1985}.

Under the ratified v3.1 Semantic Commonwealth charter, human care and survival floors ($B_{\mathrm{baseline}}$ nourishment, potable water, thermal shelter, $R_0$ domestic care, child and elder stewardship, apprenticeship teaching, and acute medical triage) are \textbf{strictly non-commensurable} with tradable exergy credits:
\begin{equation}
  \texttt{domestic\_care\_token\_minting} \;\equiv\; 0.
  \label{eq:care-non-commensurability}
\end{equation}
Within \texttt{col-commonsd}, every resource ontology IRI under \texttt{https://w3id.org/collective/v1/taxonomy} maps to a strongly typed 16-bit \texttt{ResourceDomainClass}. Any attempt to submit an \texttt{AgoraOrderV3} targeting the \texttt{0x0000..0x0FFF} reserved care and baseline survival range is deterministically rejected at Layer~6 ingress with \texttt{ERR\_CARE\_NON\_COMMENSURABLE} before reaching the order book.

\begin{invariant}[Strict Care Non-Commensurability]
\label{inv:care-non-commensurability}
Let $\mathcal{T}_{\mathrm{care}}$ denote the set of ontology classes covering $R_0$ household care, $B_{\mathrm{baseline}}$ nutrition and shelter, child/elder care, pedagogy, and clinical triage, and let $\mathcal{B}_{\mathrm{CDA}}$ denote the active order book of \texttt{col-commonsd}. For every tick $t$, $\mathcal{B}_{\mathrm{CDA}}(t) \cap \mathcal{T}_{\mathrm{care}} = \varnothing$, and the cumulative exergy or mutual-credit units minted from domestic care activities satisfies $\sum_{t} \Delta E_{\mathrm{care}}(t) = 0$.
\end{invariant}

\subsection{Upgrading \texttt{AgoraOrder} to Pure 64-Bit Integer Microjoules (\texttt{AgoraOrderV3})}

In the early Phase~1 prototype (\texttt{src/daemons/col-commonsd/main.cpp:226--298}), \texttt{AgoraOrder} and \texttt{AgoraExecution} represented prices and quantities as IEEE-754 \texttt{double} variables (\texttt{double price\_exergy\_mj}, \texttt{double quantity\_kwh}) and cleared midpoints via floating-point division \texttt{(P\_bid + P\_ask) / 2.0} with an arbitrary \texttt{<= 0.0001} epsilon erasure check. Across heterogeneous \texttt{x86\_64} and \texttt{aarch64} nodes replaying delayed Reticulum order streams, IEEE-754 rounding modes and subnormal residuals threaten bit-exact state-root consensus.

The ratified v3.1 specification replaces all floating-point Agora fields with pure 64-bit fixed-point SI integers (\texttt{AgoraOrderV3}). Every canonical \textbf{Exergy Credit} equals exactly $1.0\,\mathrm{kWh} = 3.6\,\mathrm{MJ}$ expressed in microjoules ($\mu\mathrm{J}$):
\begin{equation}
  1\text{ Exergy Credit} \;=\; 3.6\,\mathrm{MJ} \;=\; 3{,}600{,}000{,}000{,}000\,\mu\mathrm{J} \;=\; 3.6 \times 10^{12}\,\mu\mathrm{J}.
  \label{eq:exergy-credit-uj}
\end{equation}
Because $2^{64} - 1 \approx 1.844 \times 10^{19}\,\mu\mathrm{J} \approx 5.12\,\mathrm{GWh}$, unsigned 64-bit integer microjoules represent everything from a single milliwatt-millisecond sensor pulse ($1\,\mathrm{mW} \times 1\,\mathrm{ms} = 1\,\mu\mathrm{J}$) up to bioregional hydro-storage exchanges with zero overflow and zero fractional drift.

Given a crossing highest bid $P_{\mathrm{bid}} \in \mathbb{N}$ and lowest ask $P_{\mathrm{ask}} \in \mathbb{N}$ (in $\mu\mathrm{J}$ per canonical lot unit) with $P_{\mathrm{bid}} \ge P_{\mathrm{ask}}$, deterministic Euclidean midpoint clearing computes:
\begin{equation}
  P_{\mathrm{clear}} = \left\lfloor \frac{P_{\mathrm{bid}} + P_{\mathrm{ask}}}{2} \right\rfloor, \qquad
  r_{\mathrm{odd}} = \left(P_{\mathrm{bid}} + P_{\mathrm{ask}}\right) \bmod 2 \;\in\; \{0, 1\},
  \label{eq:euclidean-midpoint-cda}
\end{equation}
where wide 128-bit intermediate addition prevents 64-bit sum overflow, ties at identical price prioritize oldest \texttt{submitted\_hlc} (FIFO time priority), and any $1\,\mu\mathrm{J}$ per-lot odd parity remainder $r_{\mathrm{odd}} \cdot Q_{\mathrm{matched}}$ is explicitly accumulated into the treaty's \texttt{commons\_remainder\_pool\_uj} register so total accounted microjoules remain strictly conserved.

\subsection{Four-Layer Settlement Descent (\texttt{L6 -> L5 -> L4 -> L3})}

Crucially, \texttt{col-commonsd} holds \textbf{zero authority} to mutate Layer~3 balances directly. A crossing match inside the Bioregional Agora produces only an unratified \texttt{AgoraCandidateMatchV3} proposal that must descend sequentially through all four sovereign verification membranes before a single microjoule settles:

\begin{enumerate}
  \item \textbf{Layer~6 (\texttt{col-commonsd} --- Candidate Discovery):} Enforces \texttt{!IsCareDomain(taxonomy\_id)}, matches crossing integer bids and asks under an active \texttt{Treaty\_CID}, computes $(P_{\mathrm{clear}}, r_{\mathrm{odd}})$, and transmits \texttt{AgoraCandidateMatchV3} inward across \texttt{/run/collective/ipc/l5\_l6.sock}.
  \item \textbf{Layer~5 (\texttt{col-kmsd} --- Cryptographic \& Constitutional Gate):} Verifies both peer nodes' anonymous BBS+ Selective Disclosure capability proofs \parencite{camenisch2004signature,w3c2022vc} without exposing individual human identities, checks that the inter-node Trust Ring distance $d_{\mathrm{ring}}(u, v)$ satisfies the ratified treaty bound $R_{\max}$, and confirms neither settlement is under restorative quarantine.
  \item \textbf{Layer~4 (\texttt{col-execd} --- Stoichiometric \& $\lambda_{\mathrm{ERC}}$ Gate):} Instantiates the treaty's deterministic BPMN Wasm escrow workflow, attaches HLC delivery timeout leases, and applies the \textbf{Asymptotic Ecological Replacement Cost} multiplier $\lambda_{\mathrm{ERC,bp}} \ge 10{,}000\,\mathrm{bp}$ ($1.0000\times$) reflecting real-time watershed or aquifer scarcity:
  \begin{equation}
    \Delta E_{\mathrm{escrow\_uj}} = \left\lfloor \frac{Q_{\mathrm{lots}} \cdot P_{\mathrm{clear}} \cdot \lambda_{\mathrm{ERC,bp}}}{10{,}000} \right\rfloor.
    \label{eq:erc-adjusted-escrow}
  \end{equation}
  As local stock $S(t)$ approaches ecological floor $S_{\mathrm{crit}}$, $\lambda_{\mathrm{ERC,bp}} \to \infty$ asymptotically, automatically pricing extractive depletion out of reach before biophysical collapse can occur \parencite{raworth2017,meadows2008}.
  \item \textbf{Layer~3 (\texttt{col-storaged} --- Pairwise Zero-Sum \texttt{BCC} Settlement):} Upon Layer~2 hardware-rooted receipt attestation (\texttt{0x02}), \texttt{col-storaged} verifies that the adjusted transfer respects the pairwise Bilateral Clearing Channel credit window $[-C_{u \to v}, +C_{v \to u}]$ and commits the zero-sum journal entry $B'_{u \to v} = B_{u \to v} - \Delta E_{\mathrm{escrow\_uj}}$, $B'_{v \to u} = -B'_{u \to v}$. If the credit bound would be breached, settlement aborts cleanly pre-actuation and yields upward to Layer~5.
\end{enumerate}

struct alignas(64) AgoraOrderV3 {
    uint64_t                order_id;
    uint64_t                submitted_hlc;      // FIFO tie-breaker at equal limit price
    uint64_t                unit_price_uj;      // Microjoules per canonical resource lot
    uint64_t                quantity_lots;      // Exact integer lots (mg, mL, or discrete units)
    std::array<uint8_t, 24> peer_claim_handle;  // Blinded 24B node/guild handle (zero raw DID)
    uint16_t                taxonomy_code;      // Must exceed 0x0FFF (non-care surplus only)

    uint32_t                reserved_zero;

struct alignas(64) AgoraCandidateMatchV3 {
    uint64_t                candidate_match_id;
    uint64_t                bid_order_id;
    uint64_t                ask_order_id;
    uint64_t                clearing_price_uj;        // Floor((P_bid + P_ask) / 2)
    uint64_t                matched_lots;             // Min(Q_bid, Q_ask)
    uint64_t                odd_remainder_pool_uj;    // ((P_bid + P_ask) % 2) * matched_lots
    std::array<uint8_t, 16> treaty_cid_prefix;        // Bound Ricardian Treaty reference
};
static_assert(sizeof(AgoraCandidateMatchV3) == 64, "Candidate match fits one 64B cache line");

enum class OrderSubmitStatus : uint8_t {
    ACCEPTED_INTO_BOOK          = 0,
    ERR_CARE_NON_COMMENSURABLE  = 1,
    ERR_ZERO_PRICE_OR_QUANTITY  = 2
};

class DeterministicExergyCda {
public:
    OrderSubmitStatus SubmitOrder(const AgoraOrderV3& order) {
        if (IsNonCommensurableCareTaxonomy(order.taxonomy_code)) {
            return OrderSubmitStatus::ERR_CARE_NON_COMMENSURABLE;
        }
        if (order.unit_price_uj == 0ULL || order.quantity_lots == 0ULL) {
            return OrderSubmitStatus::ERR_ZERO_PRICE_OR_QUANTITY;
        }
        if (order.is_bid != 0U) {
            bids_.push_back(order);
            std::sort(bids_.begin(), bids_.end(), [](const AgoraOrderV3& a, const AgoraOrderV3& b) {
                return (a.unit_price_uj != b.unit_price_uj)
                           ? (a.unit_price_uj > b.unit_price_uj)
                           : (a.submitted_hlc < b.submitted_hlc);
            });
        } else {
            asks_.push_back(order);
            std::sort(asks_.begin(), asks_.end(), [](const AgoraOrderV3& a, const AgoraOrderV3& b) {
                return (a.unit_price_uj != b.unit_price_uj)
                           ? (a.unit_price_uj < b.unit_price_uj)
                           : (a.submitted_hlc < b.submitted_hlc);
            });
        }
        return OrderSubmitStatus::ACCEPTED_INTO_BOOK;
    }

    // Emits candidate matches for L6 -> L5 -> L4 -> L3 verification (never mutates L3 directly!)
    std::vector<AgoraCandidateMatchV3> EmitCandidateMatches(
        const std::array<uint8_t, 16>& active_treaty_prefix)
    {
        std::vector<AgoraCandidateMatchV3> candidates;
        while (!bids_.empty() && !asks_.empty()) {
            AgoraOrderV3& bid = bids_.front();
            AgoraOrderV3& ask = asks_.front();
            if (bid.unit_price_uj < ask.unit_price_uj) {
                break; // Spread uncrossed
            }
            const __uint128_t sum_uj =
                static_cast<__uint128_t>(bid.unit_price_uj) + static_cast<__uint128_t>(ask.unit_price_uj);
            const uint64_t clear_uj = static_cast<uint64_t>(sum_uj / 2U);
            const uint64_t odd_bit  = static_cast<uint64_t>(sum_uj % 2U);
            const uint64_t qty      = std::min(bid.quantity_lots, ask.quantity_lots);

            candidates.push_back(AgoraCandidateMatchV3{
                .candidate_match_id    = ++next_match_id_,
                .bid_order_id          = bid.order_id,
                .ask_order_id          = ask.order_id,
                .clearing_price_uj     = clear_uj,
                .matched_lots          = qty,
                .odd_remainder_pool_uj = odd_bit * qty,
                .treaty_cid_prefix     = active_treaty_prefix
            });

            bid.quantity_lots -= qty;
            ask.quantity_lots -= qty;
            if (bid.quantity_lots == 0ULL) bids_.erase(bids_.begin());
            if (ask.quantity_lots == 0ULL) asks_.erase(asks_.begin());
        }
        return candidates;
    }

private:
    std::vector<AgoraOrderV3> bids_{};
    std::vector<AgoraOrderV3> asks_{};
    uint64_t next_match_id_{0ULL};
};

} // namespace col::commons::v3

\section{The 4-Stage Tripartite Ricardian Treaty Compiler}

\subsection{The Tripartite Legal Chassis}
