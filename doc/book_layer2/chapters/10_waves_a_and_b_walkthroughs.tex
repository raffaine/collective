\subsection{Scenario Zero: Autopoietic Software as a Khronos-Style Layer 6 Object (\texttt{SCN-ZERO-SOFTWARE} / \texttt{zero\_software})}

In Dialogue~1 and Dialogue~2 (\texttt{D1}, \texttt{D2}), the Horizon Council clarified that Oasis (\texttt{Layer 1b}) never emulates inner guest operating systems or application binaries at Layer~1. Instead, software in The Collective is a \textbf{governed Layer~6 Software Artifact} stewarded by a dedicated \textbf{Layer~5 Working Group} ($N_s = 1 \to 12$, analogous to the Khronos Group stewarding OpenGL) across a five-phase organizational BPMN lifecycle (\textit{Friction to RFC $\to$ Working Group Charter $\to$ Inception and Build $\to$ Spec Ratification $\to$ Servicing and Dormant Equilibrium}).

At Layer~2, Scenario~Zero exhibits two exact physical behaviors:
\begin{enumerate}
    \item \textbf{Mild Thermal-Electric and Component-Wear Footprint:} Inside both a physical settlement server closet and the Oasis simulation, the three reproducible build architectures (\texttt{x86\_64}, \texttt{aarch64}, \texttt{riscv64}) operate under a Habitat Enveloping Node Server Closet Lease ($\mathtt{max\_acoustic\_cb} = 4{,}200\,\mathrm{cB}$ [$42.0\,\mathrm{dBA}$], $\mathtt{max\_power\_mw} = 450{,}000\,\mathrm{mW}$, $\mathtt{max\_thermal\_delta\_mk} = +2{,}000\,\mathrm{mK}$). High-side \texttt{INA226} DC bus shunts meter exact build exergy ($\Delta E_{\mathrm{uj}} = P_{\mathrm{mw}}\cdot\Delta t_{\mathrm{ms}}$), while paired manifold PT100 RTDs ($T_{\mathrm{inlet\_mk}}$, $T_{\mathrm{outlet\_mk}}$) and an inline turbine flowmeter ($Q_{\mathrm{coolant\_ml\_s}}$) verify that $\ge 8{,}000\,\mathrm{bp}$ ($80.0\%$) of compute waste heat is captured into the domestic hot-water or greenhouse hydronic loop (\texttt{ComputeHydronicHeatRecoveryAndBcc} in \path{src/daemons/col-execd/execd_self_host.hpp}). Simultaneously, \texttt{col-sensord} tracks cooling-fan tachometer RPM and NVMe SSD SMART write-wear basis points for \textit{The Workshop} lens.
    \item \textbf{Substrate Drift Wake-Up from Dormant Equilibrium (``The \TeX\ Asymptote''):} When a Scenario~Zero software package reaches rock-solid maturity, servicing tickets drop to zero and working-group operational reputation $R_i(t) \to 0$ while the non-decaying civic baseline $B = 1$ ($10{,}000\,\mathrm{bp}$) protects the repository against single-maintainer hijack. When a physical Layer~2 sensor revision drifts underneath the stationary specification (e.g., a new soil probe firmware revision emitting 24-bit dielectric frames), \texttt{col-telemetryd} flags \texttt{STATUS\_SUBSTRATE\_DRIFT\_SCHEMA\_MISMATCH}, triggering a Layer~4 hard-block that decompiles into a Layer~6 \textit{Scenario Zero Forge Studio} Semantic Diff Card to wake the working group.
\end{enumerate}

\subsection{Scenario Tau: Clean-Slate Genesis and Stage I Shim Bootstrapping (\texttt{SCN-TAU-GENESIS} / \texttt{tau\_genesis})}

Scenario~Tau models Day-0 bring-up on Lot~402 ($N_s = 1 \to 4$ founding stewards starting with the $\$20{,}000$ / \texttt{2,000,000 cents} reserve $\Phi_0$):
\begin{enumerate}
    \item \textbf{Silicon Birth and JTAG Fuse Lockout:} Stewards flash the deterministic Zephyr RTOS image onto the four-node homestead cluster (\texttt{node-01:office}, \texttt{node-02:garage}, \texttt{node-03:garden}, \texttt{node-04:hearth}) via Serial Wire Debug (\texttt{SWD}), trigger internal thermal-avalanche key generation inside each \texttt{ATECC608A} Slot~0, and blow the external JTAG readback fuse.
    \item \textbf{Clean-Slate Hardware Gate (\texttt{DENIED\_NO\_L2\_SENSOR}):} On Day~1, \texttt{SharedStackRuntime} boots with zero phantom sensors. Any query to an uncommissioned register returns \texttt{DENIED\_NO\_L2\_SENSOR}, keeping Layer~4 tasks in \texttt{MANUAL\_HUMAN\_OBSERVATION} until physical transducers (\texttt{enclosure\_env\_v1}, \texttt{soil\_probe\_v1}, \texttt{irrigation\_valve\_v1}, \texttt{culinary\_vessel\_v1}) are physically wired and cryptographically attested.
    \item \textbf{Booting on Stage~I Scavenged Layer~7 Appliances:} Rather than exhausting $\Phi_0$ on luxury gear, the household acquires a Craigslist commercial refrigerator, an induction stockpot, and a used washing machine, wrapping each in a Tier~3 \texttt{RP2040} Parasitic Layer~2 Shim (\texttt{QUALITY\_SCAVENGED\_L7\_SHIM = 0x04}) under the Lot/House Genesis Envelope ($\le 5{,}500\,\mathrm{cB}$ daytime / $\le 3{,}800\,\mathrm{cB}$ nighttime, $\le 9{,}600{,}000\,\mathrm{mW}$ main breaker).

\subsection{Scenario Sigma: Somatic Homeostasis, Modal Vibration, and Zero-Stat Liberation (\texttt{SCN-SIGMA-BURNOUT} / \texttt{sigma\_burnout})}

    \item \textbf{Rhizosphere Soil \& Autonomous Irrigation (\texttt{soil\_probe\_v1} \& \texttt{irrigation\_valve\_v1}):} Across 28 staggered legume/brassica beds, FDR probes report $\mathtt{moisture\_vwc\_bp}$, $\mathtt{soil\_temp\_mk}$, $\mathtt{nitrogen\_ppm}$, $\mathtt{phosphorus\_ppm}$, $\mathtt{potassium\_ppm}$, $\mathtt{organic\_carbon\_bp}$, and $\mathtt{ph\_centi}$ over isolated RS-485.
