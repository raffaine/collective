\chapter{Telemetry Ingestion and Sensor Oracles}

\section{The Physical-Cognitive Bridge}
Layer 4 is the cognitive brain of the Sovereign Stack, but it cannot see or touch the physical world directly. It relies entirely on Layer 2 (The Sensor/Edge Mesh) to detect reality. However, sensors are inherently noisy, prone to failure, and susceptible to adversarial tampering. A single faulty thermal probe in the community compost (Scenario Gamma) could cause the Orchestrator to mint fraudulent value tokens. The system requires a rigorous, cryptographically secure ingestion pipeline to convert raw physical telemetry into actionable, high-confidence Intents.

\section{The Sensor Oracle Contract}
To bridge this gap, Layer 4 interacts with Layer 2 via localized \texttt{SensorOracle} smart contracts deployed on Layer 3. The Orchestrator never polls a piece of hardware directly. Instead, edge microcontrollers (like ESP32s reading analog voltage from an aquifer flow meter) cryptographically sign their raw data feeds and push them to the Oracle contract.

The Orchestrator's ingestion engine subscribes to these Oracle events. To prevent single-sensor spoofing, the engine enforces threshold logic. For example, in Scenario Epsilon (Epistemic Coworking), the system will not trigger an \texttt{HVACSetbackIntent} based on a single PIR motion sensor claiming the room is empty. The ingestion engine requires a cryptographic consensus: the PIR sensor, the CO2 concentration drop, and the Bluetooth beacon registry must all independently commit events to the Oracle confirming the room's vacancy. Only when the mathematical threshold $\hat{y} = \text{median}(y_1, \dots, y_n)$ is satisfied does the Orchestrator synthesize these raw events into a cohesive \texttt{OccupancyUpdateIntent}.

\section{Buffer Queues and Signal Debouncing}
Physical phenomena fluctuate rapidly, but orchestrating physical infrastructure (like firing up an industrial induction kiln in Scenario Theta or isolating a microgrid in Scenario Upsilon) carries massive thermodynamic inertia. 

If the ingestion engine reacted to every microsecond fluctuation in telemetry, the resulting "BPMN thrashing" would destroy the physical relays. To solve this, the Layer 4 ingestion pipeline utilizes advanced signal debouncing and Queueing Theory buffers (such as $M/M/c$ queues). Raw telemetry is mathematically smoothed (e.g., via exponentially weighted moving averages) before it is permitted to trigger a state transition. 

This strict abstraction layer ensures that the BPMN Orchestrator operates in a clean, deterministic environment, reacting only to verified, consensus-backed shifts in physical reality.
