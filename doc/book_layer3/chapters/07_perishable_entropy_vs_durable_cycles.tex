\section{Why Layer 3 Separates Perishable Biological Entropy from Durable Mechanical Cycles (\texttt{CCI-3})}
\label{sec:ch7-thermodynamic-split}

In Dialogue~5 (\texttt{D5}), the Council established that Layer~6 is an HTTP-like semantic protocol layer served locally by \texttt{col-commonsd} and \texttt{col-gatewayd} below a plural constellation of specialized Application Lenses. Foremost among those lenses are \textbf{\textit{The Pantry}} (the perishable biological entropy lens) and \textbf{\textit{The Workshop}} (the durable mechanical cycles lens).

Crucially, because neither \textit{The Pantry} nor \textit{The Workshop} is hardcoded inside Oasis's Layer~1 simulation engine---both are native Collective applications running over the Sovereign Stack---an autonomous Oasis agent and a real household on Lot~402 execute the exact same stock, expiration, and tool-custody logic. To support that separation without floating-point drift, Layer~3 (\texttt{col-storaged}) partitions its material asset store into two distinct thermodynamic state machines:
\begin{enumerate}
    \item \textbf{\texttt{PantryPerishableBatchV50} (Continuous Arrhenius Thermal-Time Integration):} Models food, seed stocks, biological cultures, and clinical cold-chain reagents (\texttt{Scenario Gamma}, \texttt{Scenario Delta}, \texttt{Scenario Chi}) whose remaining biological time-to-live (TTL) degrades continuously as an exponential function of ambient storage temperature $T(t) \in \mathrm{mK}$ \parencite{arrhenius1889}.
    \item \textbf{\texttt{WorkshopDurableToolTwinV50} (Calendar-Agnostic Discrete Usage-Cycle Amortization):} Models hand tools, CNC spindles, induction furnaces, looms, and cargo-trike drivetrains (\texttt{Scenario Alpha}, \texttt{Scenario Beta}, \texttt{Scenario Theta}, \texttt{Scenario Nu}) that suffer near-zero degradation while resting dry on a tool rack and age strictly as a function of discrete operational work cycles, spindle milliseconds, and mechanical torque integrals.
\end{enumerate}

\section{Arrhenius Thermal-Time Kinetics in \textit{The Pantry} Ledger}
\label{sec:ch7-arrhenius-kinetics}

In physical biochemistry, the spoilage rate $k(T)$ of a perishable biological lot is governed not by wall-clock hours alone, but by Svante Arrhenius's activation-energy law \parencite{arrhenius1889}:
\begin{equation}
k(T) = A \cdot \exp\left(-\frac{E_a}{R \cdot T}\right)
\label{eq:ch7-arrhenius}
\end{equation}
where $E_a$ is the spoilage activation energy, $R$ is the universal gas constant, and $T$ is absolute temperature in kelvins. A batch of raw milk or vaccine vials stored at an ideal cold-chain reference temperature $T_{\mathrm{ref}} = 277{,}150\,\mathrm{mK}$ ($4.0\,^\circ\mathrm{C}$) degrades at nominal baseline speed $M_{\mathrm{rate}}(T_{\mathrm{ref}}) = 10{,}000\,\mathrm{bp}$ ($1.0000\times$). If a Stage~I scavenged refrigerator suffers a compressor fault and drifts up to $T = 287{,}150\,\mathrm{mK}$ ($14.0\,^\circ\mathrm{C}$), microbial respiration accelerates by a $Q_{10}$ factor of $2.2\times$ to $3.0\times$ ($22{,}000\text{--}30{,}000\,\mathrm{bp}$).

To evaluate Equation~\eqref{eq:ch7-arrhenius} deterministically in \texttt{col-storaged} with zero floating-point opcodes, each perishable archetype defines a reference cold-chain temperature $T_{\mathrm{ref},\mathrm{mK}}$, a nominal shelf life $\mathrm{TTL}_{0,\mathrm{ms}}$ at $T_{\mathrm{ref},\mathrm{mK}}$, and an integer $Q_{10,\mathrm{bp}}$ doubling coefficient per $10{,}000\,\mathrm{mK}$ ($10.0\,\mathrm{K}$) excursion. Over each Layer~2 telemetry interval $\Delta t_{\mathrm{ms}}$ at measured temperature $T_{\mathrm{mK}}$, the effective biological TTL consumption $\Delta \tau_{\mathrm{bio},\mathrm{ms}}$ is integrated in fixed point:
\begin{equation}
\Delta \tau_{\mathrm{bio},\mathrm{ms}} = \left\lfloor \frac{\Delta t_{\mathrm{ms}} \cdot \Phi_{\mathrm{Arrhenius},\mathrm{bp}}(T_{\mathrm{mK}}, T_{\mathrm{ref},\mathrm{mK}}, Q_{10,\mathrm{bp}})}{10{,}000} \right\rfloor
\label{eq:ch7-arrhenius-fixed}
\end{equation}
When remaining biological TTL drops below the surplus-sharing window ($\tau_{\mathrm{rem},\mathrm{ms}} \le \tau_{\mathrm{surplus\_window},\mathrm{ms}}$) while local consumption is paused (e.g., during a spontaneous weekend detour), \texttt{col-storaged} sets \texttt{surplus\_offer\_active = 1}, enabling \textit{The Pantry} lens to broadcast an anonymous Ring~$R_1$ neighbor claim offer before the food becomes Layer~1 waste.

\section{Discrete Usage-Cycle Amortization and Custody Leases in \textit{The Workshop} Ledger}
\label{sec:ch7-workshop-ledger}

By contrast, nails, torque wrenches, circuit boards, and lathe chucks in \textit{The Workshop} ignore the calendar. For each durable asset, \texttt{col-storaged} tracks:
\begin{itemize}
    \item \textbf{Cumulative Active Duty (\texttt{cumulative\_active\_use\_ms} and \texttt{cumulative\_cycles}):} Incremented solely when Layer~2 current transformers or spindle encoders report active load under a valid Layer~4 \texttt{ActuationEnvelopeV1}.
    \item \textbf{Discrete Wear Index (\texttt{wear\_index\_bp} $\in [0, 10{,}000\,\mathrm{bp}]$) and Calibration Countdown (\texttt{cycles\_until\_calibration}):} When \texttt{wear\_index\_bp} crosses the preventive maintenance threshold ($8{,}500\,\mathrm{bp}$ on Stage~II/III tools), Layer~3 emits a predictive maintenance signal to Layer~4, slotting a 5-minute scheduled bearing or blade swap between work waves.
    \item \textbf{Finite Custody Leases (\texttt{custody\_lease\_cid} and \texttt{custody\_expiry\_hlc\_ms}):} When a steward checks out a shared tool via \textit{The Workshop} lens, Layer~3 records a finite-TTL custody lease bound to a 24-byte blinded \texttt{ClaimHandle}, automatically releasing the reservation upon return or TTL expiry.
\end{itemize}

constexpr void StepPantryArrheniusDecayV50(
    PantryPerishableBatchV50& lot,
    int64_t ambient_temp_mk,
    int64_t dt_ms,
    int64_t initial_nominal_ttl_ms) noexcept {
    if (dt_ms <= 0 || lot.remaining_bio_ttl_ms <= 0) {
        return;
    }
    lot.last_measured_temp_mk = ambient_temp_mk;
    const int64_t delta_mk = ambient_temp_mk - lot.reference_temp_mk;
    // Piecewise linear-exponential Q10 multiplier in basis points per 10,000 mK (10 K)
    int64_t rate_multiplier_bp = 10'000;
    if (delta_mk > 0) {
        const int64_t excess_slope_bp = static_cast<int64_t>(lot.q10_acceleration_bp) - 10'000;
        rate_multiplier_bp = 10'000 + ((delta_mk * excess_slope_bp) / 10'000);
    }
    const int64_t bio_burn_ms = (dt_ms * rate_multiplier_bp) / 10'000;
    lot.remaining_bio_ttl_ms = std::max<int64_t>(0, lot.remaining_bio_ttl_ms - bio_burn_ms);
    if (initial_nominal_ttl_ms > 0) {
        const int64_t consumed_ms = initial_nominal_ttl_ms - lot.remaining_bio_ttl_ms;
        lot.spoilage_hazard_bp = static_cast<uint16_t>(
            std::clamp<int64_t>((consumed_ms * 10'000LL) / initial_nominal_ttl_ms, 0, 10'000));
    }
    if (lot.remaining_bio_ttl_ms <= lot.surplus_share_window_ms && lot.remaining_bio_ttl_ms > 0) {
        lot.surplus_offer_active = 1;
    }
}
