\section{The Coordination Trilemma of Physical Commons Production}
\label{sec:ch4-coordination-trilemma}

Every material commons that produces perishable nourishment---such as a neighborhood bakery or communal commissary hearth (\texttt{Scenario Gamma})---confronts a three-way structural tension:
\begin{enumerate}
    \item \textbf{Against Surveillance Capitalism:} Commercial delivery platforms predict demand by harvesting identity-linked behavioral exhaust---tracking every citizen's purchase history, GPS location, household calendar, and dietary habits in centralized databases, then deploying algorithmic nudges and artificial scarcity timers to manufacture consumption \parencite{zuboff2019}.
    \item \textbf{Against Authoritarian Central Planning:} Twentieth-century command economies avoided market marketing by abolishing personal taste altogether, issuing standardized caloric rations from top-down planning ministries that left shelves simultaneously choked with unwanted goods and bare of what residents actually craved \parencite{scott1998}.
    \item \textbf{Against Consumer Tyranny Over Craft Workers:} If a cooperative reacts to central planning by granting all $N_p = 500$ neighborhood bread consumers voting seats inside the $N_s = 5$ person Bakery Guild, casual eaters outvote the actual bakers $500 : 5$ on dough fermentation curves, oven preheat schedules, and shift ergonomics---while verifying who is an ``eligible bread voter'' requires panoptic identity tracking at the bakery counter (\texttt{D3}, \texttt{D4}).
\end{enumerate}

The Sovereign Stack resolves this trilemma through the \textbf{Dual-Loop Bakery Architecture (\texttt{D4}, \texttt{CCI-2}, \texttt{CCI-3})}, mediated at Layer~3 by \textbf{Zero-Surveillance Cohort Appetite Weather-Maps} and \textbf{Short-Lived Auto-Expiring Pickup Intent Leases (\texttt{AnonymousAppetiteLeaseV50})}.

\section{How \textit{The Pantry} and Layer 3 Solve the ``Spontaneous Weekend Detour'' Without Surveillance}
\label{sec:ch4-weekend-detour}

Consider the physical coordination hazard posed in Dialogues~4 and~5 (\texttt{D4}, \texttt{D5}): forty neighbors express a standing preference for Saturday morning sourdough, and a bright Friday inspires twenty of them to head spontaneously into the mountains for the weekend---precisely as Dr\_Sofia's boundless-time ethos encourages. If the bakery bakes forty loaves on a static weekly pledge, twenty loaves rot into Layer~1 food waste. Conversely, if the software demands Friday afternoon check-in confirmations, Layer~6 degenerates into an intrusive digital boss.

Layer~3 and \textit{The Pantry} solve this thermodynamically through \textbf{Two-Tier Demand Signaling} and \textbf{Asynchronous Detour Absorption}:
\begin{enumerate}
    \item \textbf{Tier 0 — Ambient Taste Affinity (\texttt{AMBIENT\_TASTE\_AFFINITY = 0}):} Soft seasonal preferences shape long-horizon flour milling and crop planting (\texttt{Scenario Eta}), never immediate oven firing.
    \item \textbf{Tier 1 — Short-Lived Auto-Expiring Pickup Intent Leases (\texttt{SHORT\_LIVED\_PICKUP\_LEASE = 1}):} Near-term bake counts are driven by \textit{The Pantry} acting as a \textbf{physical stock buffer}. Only when a household's actual bread or tiffin stock on its Layer~2 load-cell shelf crosses its replenishment threshold does \textit{The Pantry} emit or renew a short-lived Layer~3 pickup intent lease with a finite Hybrid Logical Clock time-to-live (\texttt{expiry\_hlc\_ms = issued\_hlc\_ms + 43'200'000}, i.e., $12\,\mathrm{hours}$).
    \item \textbf{Silent Detour Throttling:} When a household departs for the mountains, local Layer~2 pantry consumption pauses (\texttt{auto\_throttled\_by\_detour = 1}). Stock remains above the drawdown threshold, or any active near-term lease expires silently in \texttt{col-storaged} at $\tau_{\mathrm{HLC}} \ge \texttt{expiry\_hlc\_ms}$ prior to the bakery's midnight dough-make cutoff. Outbound demand scales down automatically with \textbf{zero GPS tracking, zero calendar inspection, and zero nagging notifications}.
    \item \textbf{Pre-Spoilage Neighbor Surplus Offers (\texttt{L3SurplusOffer}):} If perishable milk or greens inside a household larder approach their Arrhenius biological TTL threshold while the steward is away, \textit{The Pantry}'s standing Layer~5 rule posts an anonymous Ring~$R_1$ surplus offer into \texttt{col-storaged} so an adjacent neighbor's Pantry claims the stock before spoilage occurs.
\end{enumerate}

\begin{invariant}[Zero Persistent Consumer Histories in Layer 3]
\label{inv:ch4-zero-consumer-history}
At every HLC instant $\tau$, every record $r \in \mathcal{T}_{\mathrm{appetite}}(\tau)$ stored in \texttt{col-storaged}'s demand table satisfies:
\begin{equation}
\mathrm{Fields}(r) \cap \{ \texttt{did:peer}, \, \texttt{human\_name}, \, \texttt{ip\_address}, \, \texttt{gps\_coord} \} = \emptyset \quad \land \quad (\tau > r.\texttt{expiry\_hlc\_ms} \implies \mathrm{Active}(r) = \mathrm{false})
\end{equation}
In accordance with \textit{NAACP v.\ Alabama} data non-existence \parencite{naacp1958}, \texttt{col-storaged} physically cannot reconstruct which citizen ate which loaf.
\end{invariant}

enum class DemandCommitmentTier : uint8_t {
    AMBIENT_TASTE_AFFINITY   = 0, // Soft seasonal forecast (non-binding)
    SHORT_LIVED_PICKUP_LEASE = 1, // Firm near-term Pantry drawdown lease (auto-expires)

/**
 * @brief Zero-Surveillance Layer 3 Cohort Appetite & Auto-Expiring Pickup Lease (D4, D5, CCI-2).
 * Stripped of all personal DIDs by local Layer 5 (col-kmsd) via BBS+ ring-membership ZKP
 * before crossing l4_l5.sock -> l3_l4.sock. Strictly 64 bytes (1 cache line), zero floats.
 */
struct alignas(64) AnonymousAppetiteLeaseV50 {
    uint64_t lease_nonce_hash{0};         // [0..7]   Unlinkable PRF lease token
    uint64_t target_need_cid_prefix{0};   // [8..15]  e.g. need:sourdough_rye / need:pea_soup
    uint64_t issued_hlc_ms{0};            // [16..23] Issue timestamp (HLC ms)
    uint64_t expiry_hlc_ms{0};            // [24..31] Auto-expires on weekend detour!
    uint64_t zk_ring_membership_tag{0};   // [32..39] Verifies valid R1 neighbor without DID
    uint32_t requested_mass_mg{0};        // [40..43] Requested portion mass in milligrams
    uint32_t allergen_exclusion_mask{0};  // [44..47] Bitmask for BBS+ anaphylactic disjointness
    uint16_t taste_affinity_bp{5000};     // [48..49] 0..10000 bp flavor resonance
    uint16_t target_cohort_zone_id{1};    // [50..51] Coarse neighborhood delivery porch cluster
    DemandCommitmentTier tier{DemandCommitmentTier::SHORT_LIVED_PICKUP_LEASE}; // [52] (1B)
    uint8_t  auto_throttled_by_detour{0}; // [53]     1 if L2 Pantry consumption paused (1B)
    uint8_t  quality_flags{0x02};         // [54]     0x02=HardwareRoot, 0x01=Simulated (1B)
    uint8_t  reserved_pad[9]{0};          // [55..63] Explicit cache-line padding (9B)
};
static_assert(sizeof(AnonymousAppetiteLeaseV50) == 64,
              "AnonymousAppetiteLeaseV50 must occupy exactly 1 cache line (64 bytes).");

struct CohortBakeScheduleAllocationV50 {
    int64_t verified_staple_mass_mg{0};   // 85% staple demand backed by active non-expired leases
    int64_t montage_experiment_mass_mg{0};// 15% capacity reserved for Dr_Sofia culinary montage
    uint32_t active_lease_count{0};
    uint32_t detour_expired_count{0};
};

[[nodiscard]] constexpr CohortBakeScheduleAllocationV50 AggregateActiveBakeryDemandV50(
    const AnonymousAppetiteLeaseV50* leases,
    std::size_t count,
    uint64_t current_hlc_ms,
    uint64_t target_need_cid,
    int64_t montage_reserve_bp = 1'500) noexcept {
    CohortBakeScheduleAllocationV50 out{};
    for (std::size_t i = 0; i < count; ++i) {
        const auto& l = leases[i];
        if (l.target_need_cid_prefix != target_need_cid ||
            l.tier != DemandCommitmentTier::SHORT_LIVED_PICKUP_LEASE ||
            l.zk_ring_membership_tag == 0) {
            continue;
        }
        // Automatic weekend detour throttling: drop paused or HLC-expired leases
        if (l.auto_throttled_by_detour != 0 || current_hlc_ms >= l.expiry_hlc_ms) {
            ++out.detour_expired_count;
            continue;
        }
        out.verified_staple_mass_mg += static_cast<int64_t>(l.requested_mass_mg);
        ++out.active_lease_count;
    }
    // 85% staple / 15% montage split: total = staple / 0.85 -> montage = staple * 1500 / 8500
    const int64_t staple_share_bp = 10'000 - montage_reserve_bp;
    if (staple_share_bp > 0 && out.verified_staple_mass_mg > 0) {
        out.montage_experiment_mass_mg =
            (out.verified_staple_mass_mg * montage_reserve_bp) / staple_share_bp;
    }
    return out;
}
