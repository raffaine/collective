\chapter{Consensus and Sybil Resistance}

\section{The Cybernetic Brain}
If Layer 1 is the thermodynamic metabolism and Layer 2 is the sensory nervous system, Layer 3 is the decentralized brain. The Cryptographic Ledger is responsible for maintaining the absolute, unified state of the Sovereign Node without relying on a central authority. It ingests the cryptographically signed telemetry payloads from Layer 2 (e.g., INA226 ADC outputs) and reaches consensus on the physical reality of the node.

\section{Proof of Physical Work (Scenario 0)}
Legacy blockchains rely on abstract Proof of Work (PoW) (wasting energy on arbitrary SHA-256 hashes) or Proof of Stake (PoS) (oligarchic capital). The Sovereign Stack utilizes \textit{Proof of Physical Work (PoPW)}. 

In Scenario 0, the node must track its own thermodynamic exergy consumption. The Layer 2 Hardware Security Modules (HSMs) sign the actual physical power draw ($P = V \times I$). To mint a foundational Exergy Token ($E_T$), a node cannot simply compute hashes; it must prove it dissipated actual Joules of thermodynamic energy into the environment. 

The state transition function for the ledger is constrained by the First Law of Thermodynamics. A node proposes a block containing a batch of L2 exergy signatures. The network validates the block by verifying the physical limits:
\begin{equation}
\sum E_{minted} \le \eta_{sys} \sum \left( V_{shunt} \cdot I_{bus} \cdot \Delta t \right)
\end{equation}
where $\eta_{sys}$ is the established thermodynamic efficiency bound from Layer 1. If a node proposes a block claiming more exergy than its historical physical capacity, the network automatically rejects the block as an oracle spoofing attack.

\section{Byzantine Fault Tolerance in Microgrids (Scenario Upsilon)}
During a macroeconomic shock (Scenario Upsilon), the microgrid islands itself. The ledger must continue operating even if some nodes fail or are compromised by adversaries. The consensus mechanism utilizes Practical Byzantine Fault Tolerance (pBFT). 

For the mesh to finalize a block of physical state, a supermajority of validation nodes must agree. The system can tolerate up to $f$ malicious or faulty nodes out of a total $N$ nodes, bounded by the inequality:
\begin{equation}
N \ge 3f + 1
\end{equation}
If the microgrid sheds non-essential loads via Layer 2 Solid-State Relays, the surviving active nodes dynamically adjust their BFT validator set sizes, ensuring that consensus can be reached even in a severely degraded thermodynamic state \cite{castro1999practical}.

\section{Directed Acyclic Graphs for High-Frequency Telemetry (Scenarios Beta \& Nu)}
Traditional synchronous blockchains suffer from artificial block-time delays, rendering them incapable of processing high-frequency IoT data. For tracking the rapid, continuous physical transit of cargo bikes (Scenario Beta) or the real-time UHF RFID backscatter of decentralized supply chains (Scenario Nu), Layer 3 pivots to a Directed Acyclic Graph (DAG) consensus model.

In a DAG architecture, there are no "miners" or "blocks." Instead, every new transaction (e.g., an IMU location update) must cryptographically validate two previous transactions before it is attached to the tangle. As the network activity rate $\lambda$ (modeled via a Poisson distribution) increases, the confirmation time paradoxically decreases. The cumulative weight $W_x$ of a transaction $x$ grows as subsequent transactions reference it:
\begin{equation}
W_x = 1 + \sum_{y \in \text{approvers}(x)} W_y
\end{equation}
This asynchronous, feeless topology is mandatory for the micro-second tracking of physical assets \cite{popov2016tangle}.

\section{Decentralized Oracle Aggregation (Scenarios Gamma, Eta, Mu)}
When quantifying macroscopic biological mass—such as organic compost (Scenario Gamma), coppice timber (Scenario Eta), or bio-digester methane outputs (Scenario Mu)—relying on a single Layer 2 Wheatstone bridge creates a central point of failure. 

To prevent physical spoofing, the ledger mandates Oracle Aggregation using threshold cryptography. A decentralized network of independent load cells signs their mass observations. The ledger only accepts the physical state change if a threshold $t$ of $n$ oracles agree within a statistical variance $\sigma^2$. The aggregate truth $\hat{y}$ is derived via the median of the signed payloads, ruthlessly discarding outlier attacks:
\begin{equation}
\hat{y} = \text{median}(y_1, y_2, \dots, y_n)
\end{equation}
