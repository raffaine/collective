\section{Dual-Mode Layer 7 Reach and Cooperative Legal Carapace}
Scenario Xi (\texttt{docs/scenarios/xi\_architecture/}, Wave~D, Stage~1A $\to$ 3) replaces speculative developer tract housing and irreversible glued-drywall demolition waste with \textbf{Two-Track Parametric Open Building} \parencite{habraken1972supports,brand1994buildings}: a 200-year nail-free reversible \textit{Kigumi} mass-timber structural chassis (\textbf{Track~1}) paired with steward-customizable interior infill partitions (\textbf{Track~2}) pre-engineered to satisfy \textbf{Enveloping Node Hypervisor} acoustic and thermal isolation invariants.
\begin{itemize}
    \item \textbf{Layer~7 Reach Mode:} \textit{Dual-Mode (Defensive Ministerial Building-Code Carapace \& Transitional Glazing/Electrical Conduit Procurement)}. Avoids discretionary zoning variance battles by compiling parametric blueprints directly into ministerially approved statutory building code appendices stamped by cooperative Professional Engineers (PE).
    \item \textbf{US / Common-Law Carapace:} State ADU / Middle-Housing Preemption Statutes (e.g., California SB~9/SB~10, Washington HB~1110/HB~1337) combined with \textbf{International Residential Code (IRC) Appendix~AQ (Tiny Houses), Appendix~AR (Light Straw-Clay), and Appendix~AS (Straw-Bale Construction)}, constructed by an IRC Subchapter~T Builders' Guild ground-leasing from the \texttt{Scenario Zeta} CLT.
    \item \textbf{Brazilian / Lusophone Carapace (\texttt{bra/README.md}):} \textit{Constru{\c{c}}{\~a}o Autogestion{\'a}ria sob Termo de Territorialidade Coletiva (TTC, \texttt{Lei 13.465/2017})} and \textit{Cooperativa de Habita{\c{c}}{\~a}o e Constru{\c{c}}{\~a}o Civil} (\texttt{Lei 12.690/2012}), compliant with \textbf{ABNT NBR~7190 (Timber Structures)} and \textbf{ABNT NBR~15575 (Acoustic \& Thermal Performance)} via cooperative CREA/CAU technical responsibility (\texttt{ART/RRT}).
\end{itemize}
