\chapter{API Parasitism and Cryptographic Oracles}

\section{Leeching the Web2 Data Layer}
Before the Sovereign Stack achieves total hardware sensor density (Layer 2), it must rely on legacy data structures. Weather forecasts, municipal transit schedules, and global supply chain pricing are locked within Web2 APIs. Layer 7 actively leeches this data to feed the internal Layer 4 Orchestrator without becoming dependent on the stability of the Web2 host.

\section{The Edge Oracle Network}
Layer 7 implements \textit{API Parasitism} via a decentralized Edge Oracle Network. Instead of a single central server querying a municipal API, multiple edge nodes within the local mesh independently query the Web2 endpoint. 

These nodes aggregate the JSON responses and execute a consensus mechanism. If 3 out of 5 nodes agree on the data (e.g., the state weather API declares an impending freeze), the nodes mathematically sign a consolidated \texttt{OracleIntent}. This payload is ingested by Layer 5 to trigger internal policies (such as preemptively rerouting microgrid power to community heaters). 

\section{Mitigating Host Failure}
Because legacy APIs frequently deprecate, rate-limit, or suffer outages, the Edge Oracles employ fallback decay logic. If the Web2 host goes offline, the Layer 4 Orchestrator gracefully decays its confidence interval, transitioning from precise API data to localized heuristics generated by its own internal sensors, ensuring the mesh never halts due to external server failure.

\section{Iterative Refinement: Supply Chain Parasitism}
Scenario Mu (Extraction) revealed a critical gap: before Layer 1 (Physical Fabrication) is fully autonomous, the community must procure raw materials and semiconductors from legacy, global supply chains. Layer 7 implements \textit{Logistics Parasitism}. The Oracle network interfaces with legacy procurement and shipping APIs (e.g., DHL, Alibaba) to automatically route physical hardware to decentralized drop-points. Once the hardware crosses the physical perimeter, the API bridge is severed, and the asset is cryptographically ingested into the Sovereign Stack's internal inventory.
