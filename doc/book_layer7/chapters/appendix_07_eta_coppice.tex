\chapter{Appendix Eta: The Coppice Scenario}

\section{The Legacy Dependency (Technical \\\& Cultural)}
Eta Nodes focus on ecological management and forestry. Legacy dependencies include state environmental protection agency monitoring, agricultural subsidies, legacy land deeds (fiat property rights), and industrial timber supply chains. Culturally, there is a reliance on extractive yield metrics and centralized ecological enforcement.

\section{The Parasitic Bridge (Technical \\\& Legal)}
A Land Trust wrapper holds the fiat title to the forest. Layer 7 cryptographic oracles pull data from state meteorological APIs and satellite services to optimize planting. The node temporarily leverages state agricultural subsidies, funneling the fiat directly into Layer 3 escrow to fund autonomous drone monitoring and soil regeneration efforts, effectively forcing the legacy state to subsidize its own obsolescence.

\section{The Decoupling Trigger}
The trigger is reached when the node's internal ecological sensing network (Layer 2) surpasses the resolution and reliability of state API data, and when the internal mesh economy can fully sustain the land trust's minimal property tax obligations without external subsidies. The exact metric is the internal sensor density exceeding 50 nodes per hectare with a 99\% uptime over 12 months.

\section{Orchestration \\\& Ethical Mechanics}
Orchestration involves smart contracts that automatically deploy regenerative tasks (e.g., selective pruning) based on oracle data. Ethically, the system bridges the gap between indigenous ecological knowledge and cybernetic management, ensuring that local populations retain foraging and stewardship rights, preventing the "financialization of nature" while extracting necessary operating capital from state programs.
