\section{Why Capitalist Markets Manufacture Fragmentation and How Layer 3 $\lambda_{\mathrm{ERC}}$ Dissolves It}
\label{sec:l7-erc-convergence}

In a Layer~7 price-mediated market, incompatible physical interfaces are not an engineering accident; they are a deliberate financial moat. By changing the plastic rib geometry on a battery pack or the mounting flange on a water filter, a corporation engineers artificial switching costs and captures a monopoly annuity on replacement consumables while externalizing the embodied energy of redundant chargers, molds, and landfill waste onto the biosphere \parencite{georgescu1971entropy,perzanowski2022right}.

Once a settlement replaces scalar price optimization with Layer~3 \textbf{Ecological Replacement Cost ($\lambda_{\mathrm{ERC}}$)} accounting in \texttt{col-storaged}, artificial differentiation exposes itself immediately as pure thermodynamic waste:

\begin{theorem}[Emergent Modular Convergence Under $\lambda_{\mathrm{ERC}}$ Gradient Descent]
\label{thm:l7-modular-convergence}
Recall from Equation~(\ref{eq:ch2-erc-formula}) that the Ecological Replacement Cost per cycle of a component $c$ is:
\begin{equation}
\lambda_{\mathrm{ERC}}(c) = E_{\mathrm{embodied}}(c) + E_{\mathrm{transport}}(c) + \frac{E_{\mathrm{retooling\_amortized}}(c)}{N_{\mathrm{reuse\_cycles}}(c)} - E_{\mathrm{recoverable\_stock}}(c)
\label{eq:ch4-erc-repeat}
\end{equation}
Compare a bespoke proprietary component $c_{\mathrm{prop}}$ against an open modular standard component $c_{\mathrm{mod}}$ (such as a Gastronorm \texttt{GN 1/1} stainless pan, an ISO $600 \times 400\,\mathrm{mm}$ Euro-tote, or an ISO metric \texttt{M6}/\texttt{M8} socket-head cap screw):
\begin{enumerate}
    \item \textbf{Cross-Scenario Reuse Multiplier ($N_{\mathrm{reuse\_cycles}}$):} Because $c_{\mathrm{mod}}$ fits ovens in \texttt{Scenario Gamma}, cargo-trike racks in \texttt{Scenario Beta}, sterilization autoclaves in \texttt{Scenario Chi}, and parts bins in \texttt{Scenario Alpha}, its active reuse pool satisfies $N_{\mathrm{reuse\_cycles}}(c_{\mathrm{mod}}) \gg N_{\mathrm{reuse\_cycles}}(c_{\mathrm{prop}})$, driving $\frac{E_{\mathrm{retooling\_amortized}}}{N_{\mathrm{reuse\_cycles}}} \to 0$.
    \item \textbf{Closed-Loop Local Recoverability ($E_{\mathrm{recoverable\_stock}}$):} Standard 304/316 stainless pans and metric fasteners can be cleaned, re-threaded, or remelted in \texttt{Scenario Theta} with $E_{\mathrm{recoverable\_stock}}(c_{\mathrm{mod}}) \ge 0.92\,E_{\mathrm{embodied}}(c_{\mathrm{mod}})$, whereas multi-material glued plastic proprietary housings yield $E_{\mathrm{recoverable\_stock}}(c_{\mathrm{prop}}) \approx 0$.
    \item \textbf{Voluntary Gradient Descent Without Central Bureaucracy:} Because Layer~4's Petri-net solver (\texttt{col-execd}) schedules paths that minimize $\sum (E_{\mathrm{direct}} + \lambda_{\mathrm{ERC}})$ and Layer~6's Sovereign Library browser ranks open-source franchise blueprints by empirical \texttt{collective:thermodynamicProof} (\texttt{CCI-5}), autonomous nodes voluntarily converge on open modular standards without any central ministry issuing top-down decrees.
\end{enumerate}
\end{theorem}

\section{The Two-Zone Metrological Invariant: Canonical 64-Bit SI Core vs.\ Layer 6 Edge Localization (\texttt{CCI-6})}
\label{sec:l7-two-zone-metrology}

Alongside physical hardware fragmentation, the legacy Layer~7 world suffers from metrological fragmentation: American supplier catalogs quote dimensions in fractional inches and temperatures in degrees Fahrenheit; traditional bakers specify dough formulas in baker's percentages or volumetric cups; acoustic ordinances cite A-weighted decibels (\texttt{dBA}); and commercial utilities bill in kilowatt-hours (\texttt{kWh}) and therms.

If a cyber-physical operating system allowed mixed units or IEEE-754 floating-point numbers inside its control and ledger daemons, it would invite two catastrophic failures:
\begin{enumerate}
    \item \textbf{Dimensional Mismatch Disasters:} The classic 1999 Mars Climate Orbiter failure (where a Lockheed Martin legacy module emitted pound-force seconds while NASA's core expected newton-seconds); and
    \item \textbf{Cross-Architecture Floating-Point Drift:} IEEE-754 \texttt{float} and \texttt{double} rounding differences across \texttt{x86\_64}, \texttt{aarch64}, and \texttt{riscv64} processors break Merkle-CRDT hash consensus in Layer~3 and reproducible WASM execution in Layer~4.
\end{enumerate}

Dialogue~8 (\texttt{D8}) and Cross-Cutting Invariant~\textbf{CCI-6} resolve this permanently through the \textbf{Two-Zone Metrological Invariant}:
\begin{itemize}
    \item \textbf{Zone~1 --- The Canonical 64-Bit Fixed-Point SI Cybernetic Core (Layers~2, 3, 4, and~5):} Every internal wire struct, sensor register, BPMN parameter, Enveloping Node boundary lease, and ledger balance executes exclusively in 64-bit signed/unsigned fixed-point SI integers (\texttt{uJ}, \texttt{mW}, \texttt{mg}, \texttt{ug}, \texttt{mm}, \texttt{um}, \texttt{mL}, \texttt{uL}, \texttt{mK}, \texttt{cB}, \texttt{ms}, \texttt{us}, \texttt{bp}; \texttt{floating\_point\_opcodes == 0}).
    \item \textbf{Zone~2 --- The Layer~6 Human Edge Localization Lens and Layer~7 Catalog Translator:} Layer~6 (\texttt{col-commonsd} + Application Lenses) never forces a human baker to type millikelvins or microjoules. Instead, Layer~6 acts as a deterministic localization lens at the human edge, converting craft or regional idioms (\texttt{78\% hydration}, \texttt{1.5 inches}, \texttt{165.2 °F}, \texttt{42 dBA}) into canonical fixed-point SI integers prior to Stage~4 Deterministic Read-Back and hardware Ed25519 signature. Symmetrically, when Layer~7 (\texttt{col-adversaryd}) generates an external vendor purchase order against a legacy supplier catalog, it translates the canonical SI requirement (\texttt{38,100 um} length, \texttt{6,000 um} diameter) into the vendor's legacy catalog SKU string while keeping all internal accounting strictly in SI.
\end{itemize}

#pragma once
#include <cstdint>

namespace collective::l7 {

struct ProcurementItemCandidateV50 {
    uint64_t vendor_sku_hash{0};
    int64_t  unit_price_cents{0};
    int64_t  embodied_exergy_uj{0};
    int64_t  transport_exergy_uj{0};
    int64_t  retooling_amortized_uj{0};
    int64_t  expected_reuse_cycles{1};
    int64_t  recoverable_stock_uj{0};
    bool     conforms_to_gn_iso_metric_standard{false};
    bool     has_open_cad_and_schematic{false};
    bool     contains_drm_or_potted_pcb{false};
};

[[nodiscard]] constexpr int64_t ComputeCandidateErcPerCycleUj(
    const ProcurementItemCandidateV50& item) noexcept {
    const int64_t cycles = (item.expected_reuse_cycles > 0) ? item.expected_reuse_cycles : 1;
    const int64_t retooling_term = item.retooling_amortized_uj / cycles;
    const int64_t gross_uj = item.embodied_exergy_uj + item.transport_exergy_uj + retooling_term;
    return (gross_uj > item.recoverable_stock_uj) ? (gross_uj - item.recoverable_stock_uj) : 0;
}

/**
 * @brief Layer 7 Modular Procurement Gate:
 * Rejects DRM-locked / potted replacements when an open modular (GN/ISO/M6) or
 * Right-to-Repair conformant candidate satisfies the physical SI specification.
 */
[[nodiscard]] constexpr bool IsCandidateEligibleForNeedsListV50(
    const ProcurementItemCandidateV50& candidate,
    int64_t max_allowed_erc_per_cycle_uj,
    bool emergency_stage1a_bootstrap_exception = false) noexcept {
    if (candidate.contains_drm_or_potted_pcb && !emergency_stage1a_bootstrap_exception) {
        return false; // Blocked: prevents new Stage I shim-tax debt from entering the node
    }
    if (!candidate.conforms_to_gn_iso_metric_standard && !emergency_stage1a_bootstrap_exception) {
        return false; // Enforces Gastronorm, ISO Euro-tote, and M6/M8 One-Wrench modularity
    }
    return ComputeCandidateErcPerCycleUj(candidate) <= max_allowed_erc_per_cycle_uj;
}
