# Layer 7 Legacy Integration: Architecture Generation Guide

## Core Mandate
This document governs the authoring of `doc/book_layer7/`. The Sovereign Stack cannot be born in a vacuum; it must bootstrap itself by interacting with the existing, dying world. Layer 7 is the **Parasitic Bridging Layer**. It maps the existing legacy abstractions (Fiat banking, Web2 APIs, State power grids, ISP monopolies) that we seek to strategically leech, repurpose, and ultimately render obsolete.

**Rule 1: Strategic Parasitism.** Layer 7 does not integrate with the legacy world as an equal. It integrates to extract resources (data, fiat, electricity) while strictly defending the sovereign integrity of Layers 1-6.
**Rule 2: Core Technology Chapters.** The book must be structured around core integration mechanisms rather than a catalog of scenarios. 
**Rule 3: The Obsolescence Horizon.** Every integration must have a mathematically defined sunset protocol. How does the system recognize when a legacy dependency is no longer needed and automatically sever the cord?
**Rule 4: The Scenario Appendix.** The 25 Sovereign Scenarios (Scenario 0 through Omega) will be moved to the Appendix to prove how legacy systems are leeched and deprecated in each specific domain.
**Rule 5: The Iterative Feedback Loop.** If a scenario appendix uncovers a missing bridging mechanic, the agent MUST halt, invent the solution, and **refine the Core Chapters**.

## Required Core Chapter Layout (To Be Authored)
*   **Chapter 1: The Fiat-Crypto Bridge** (How to safely ingest fiat currency into Layer 3 escrow without granting legacy banking institutions veto power or control over the mesh).
*   **Chapter 2: API Parasitism \& Cryptographic Oracles** (How to leech Web2 data—e.g., municipal weather APIs, legacy supply chain databases—and securely ingest it into Layer 4/5 logic).
*   **Chapter 3: Physical Grid Leeching** (How Layer 2 hardware intelligently draws from the state power grid or legacy ISPs when cheap, while maintaining instant islanding capabilities when the macro-grid fails).
*   **Chapter 4: The Obsolescence Horizon** (The cybernetic algorithms that monitor internal mesh density and automatically trigger the decoupling from legacy dependencies).
*   **Chapter 5: Legal Parasitism \& State Friction** (Navigating the "Hard Legal Horizons" of fiat courts, taxes, and zoning laws. How to use legacy legal wrappers like LLCs, trusts, or cooperatives as temporary shields for underlying cryptographic DAOs).
*   **Chapter 6: Cultural Norms \& Ethical Bridging** (The friction of the human transition. Navigating the memetic shock of moving from extractive capital to a sovereign commons, and the ethical boundaries of leeching a dying system without accelerating its collapse onto vulnerable populations).

## Authoring Guidelines for Each Appendix
When writing the 25 scenario appendices, strictly follow this structure:
1.  **The Legacy Dependency (Technical \& Cultural):** What old-world system or norm is currently required? (e.g., Fiat Insurance, Municipal Zoning, traditional employment contracts).
2.  **The Parasitic Bridge (Technical \& Legal):** How does Layer 7 temporarily integrate and extract value from this system while shielding the Sovereign Stack from its fragility and legal liability?
3.  **The Decoupling Trigger:** The exact metric (e.g., local solar capacity reaching 120%, legal obsolescence) that triggers decoupling.
4.  **Orchestration \& Ethical Mechanics:** Deep dive into the cryptographic gateways, legal wrappers, and cultural translations executing this bridge. If a core bridging mechanism is missing, trigger **Rule 5 (Iterative Feedback Loop)**.
