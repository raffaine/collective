# Empirical Validation Suites

This directory contains autonomous Python test suites generated by the documentation swarm. 

## Purpose
Unlike standard unit tests for code, these scripts are designed to empirically validate the mathematical, structural, and citation integrity of the Sovereign Stack documentation and LaTeX books.

### Capabilities:
- **LaTeX Structural Integrity:** Validates brace balancing, environment tags, and syntax logic.
- **Citation Resolution:** Scans `.tex` files and cross-references citation keys against the master `references.bib` file.
- **Mathematical Stress Testing:** Programmatically executes and stress-tests the equations defined in the book (e.g., PID anti-windup algorithms, Schmitt trigger hysteresis, Lyapunov damping) to ensure the theoretical math holds up under edge-case bounds before publishing.

## Execution
Run the Python scripts natively. Test output reports are generated as `*_results.json` files. These JSON logs are deliberately ignored by Git as they are ephemeral build artifacts.
